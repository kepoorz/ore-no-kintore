# 3週間が終わったら：次の12週間

> **メニューを変える前に、続けられたか・伸びたかを見る。変えるときは、一度に1つだけ。**

このページは、[はじめての3週間](first-3-weeks.md) を終えた人が次に読むページである。
見た目の変化が分かるまでには通常 8〜12週間かかる。だからここでは、その先の **12週間** をひとまとまりとして扱う。

1. [3週間後の分岐](#1-3週間後の分岐) … 同じメニューを続けるか、次のプログラムへ移るか
2. [3日版への移行手順](#2-3日版への移行手順) … いきなり全部やらず、2週間かけて増やす
3. [伸びなくなったときの診断フロー](#3-伸びなくなったときの診断フロー) … 上から順に、1つずつ
4. [12週間後に見るもの](#4-12週間後に見るもの) … 区切りの測定

---

## 1. 3週間後の分岐

選択肢は3つ。**続けられた回数** と **記録が伸びたか**（[3週間後のチェック](first-3-weeks.md#3週間後のチェック)）で決める。

| 続けられた回数 | 記録 | 次にやること |
| --- | --- | --- |
| 予定の半分くらい | どちらでも | **同じメニューをもう3週間**。先に曜日と時間を固定し直す。種目や量を増やしても、行けなければ意味がない |
| ほぼ予定どおり | 伸びた種目がない / フォームがまだ不安 | **同じメニューをもう3週間**。[3週目のルール](first-3-weeks.md#3週間の進め方)（各2〜3セット・RIR 2〜3）で続ける。量を増やす前に、今の量で伸びるかを見る |
| ほぼ予定どおり | 重さか回数が伸びた。週3回取れる | **[3日版](../programs/3-day.md) へ移る**（→ [移行手順](#2-3日版への移行手順)） |
| ほぼ予定どおり | 重さか回数が伸びた。週4回取れる | **[4日版](../programs/4-day.md) へ移る**。移行の考え方は3日版と同じ |

- 「同じメニューをもう3週間」は後退ではない。最初に伸びるのは神経で、その適応はまだ続いている（→ [最初に伸びるのは筋肉ではなく神経](first-3-weeks.md#最初に伸びるのは筋肉ではなく神経)）
- 5日版・6日版はまだ選ばない。1回の量が多く、回復が追いつかない。3日版か4日版を **最低4週間**（→ [基本の考え方](../basics/philosophy.md#2-まず何をすればいいか)）やってから考える
- 日数で迷ったら少ない方。プログラムは **継続できる日数** で選ぶ（→ [プログラムの選び方](../programs/README.md)）

### 12週間の流れ

| 週 | やること |
| --- | --- |
| 1〜2週目 | 導入期。種目数とセット数を段階的に増やす（→ [下の表](#週ごとの増やし方)） |
| 3〜8週目 | 通常どおり。[ダブルプログレッション](../basics/training-principles.md#ダブルプログレッション) で重さを伸ばす。週に1回 [ふりかえる](../templates/weekly-review.md) |
| 9〜12週目 | 続ける。2〜3週間伸びなければ [診断フロー](#3-伸びなくなったときの診断フロー)。疲れのサインが重なれば [デロード](../basics/training-principles.md#デロード) |
| 12週目の終わり | [区切りの測定](#4-12週間後に見るもの) |

## 2. 3日版への移行手順

初心者メニューと3日版の間には段差がある。いきなり全部やると、疲労だけが増えて記録は落ちる。

| 項目 | 初心者メニュー | 3日版 |
| --- | --- | --- |
| 1回の種目数 | 5 | 6〜7 |
| セット数 | 各2〜3 | 各2〜3（コンパウンドは3） |
| 回数 | 10〜12 | コンパウンドは 5〜10、補助は 8〜20 |
| RIR | 3〜4 → 2〜3 | 2（コンパウンド）、1〜2（補助） |
| 所要時間 | 45〜60分 | 75〜100分（有酸素込み） |

だから [導入期](../basics/training-principles.md#導入期新しいプログラムを始めるとき) のルールで、2週間かけて体を慣らす。

### 週ごとの増やし方

| 週 | セット数 | RIR | やること |
| --- | --- | --- | --- |
| 1週目 | 3セットと書かれた種目は **2セット**。2セットの種目はそのまま | 3 | 新しい種目は軽い重さでフォームを覚える。知っている種目は初心者メニューの重さから |
| 2週目 | 通常の 80〜90%。**コンパウンド種目（各日の #1〜3）だけ3セットに戻す**。残りは2セットのまま | 2〜3 | 回数の上限に届いた種目は、最小の刻みで重くする |
| 3週目〜 | 通常どおり | コンパウンド 2、補助 1〜2 | ダブルプログレッション。[導入期は終わり](#12週間の流れ) |

Full A を例にすると、セット数はこう変わる。

| 種目 | 1週目 | 2週目 | 3週目〜（通常） |
| --- | --- | --- | --- |
| スミスマシン・スクワット | 2 | 3 | 3 |
| スミス・フラットプレス | 2 | 3 | 3 |
| ラットプルダウン | 2 | 3 | 3 |
| 膝屈曲ハム種目 | 2 | 2 | 3 |
| 片手ケーブル・ラテラルレイズ | 2 | 2 | 3 |
| ケーブルクランチ | 2 | 2 | 2 |
| **合計** | **12** | **15** | **17** |

- 3日版のコンパウンド種目は回数が 5〜8 回と少ない。重さは上がるが、1週目は RIR 3 なので「10回できる重さで 6〜8 回止める」くらいから探る。重すぎて崩れたフォームを覚えるのが一番の損（→ [重すぎる重量をやって、それだけで疲れ果てる](first-3-weeks.md#重すぎる重量をやってそれだけで疲れ果てる)）
- 筋肉痛が強く出ても、2週目に進んでいい。筋肉痛の強さは効いたかどうかの指標にならない

### 種目の対応表

初心者メニューで覚えた動きは、3日版ではこの種目に引き継がれる。

| 初心者メニュー | 3日版 | 何が変わるか |
| --- | --- | --- |
| [レッグプレス](../exercises/leg-press.md) / [ゴブレットスクワット](../exercises/goblet-squat.md) | [スミスマシン・スクワット](../exercises/smith-squat.md)（Full A） | 自分でバーを担ぐ。1週目はバーだけ、または最小の重さでフォームから。慣れるまでレッグプレスのままでもいい（同じ動作パターン） |
| [ゴブレットスクワット](../exercises/goblet-squat.md) | [DB ブルガリアンスプリットスクワット](../exercises/bulgarian-split-squat.md)（Full B） | 片脚になる。ゴブレットで使った重さの半分以下から |
| [チェストプレス](../exercises/chest-press-machine.md) / [腕立て伏せ](../exercises/push-up.md) | [スミス・フラットプレス](../exercises/smith-bench-press.md)（Full A）、スミス・インクラインプレス（Full B） | バーを自分で支える。チェストプレスマシンは Full C にそのまま残る |
| [ラットプルダウン](../exercises/lat-pulldown.md) | ラットプルダウン（Full A） | 変わらない。回数が 6〜10 に下がるので、重さを上げる |
| [シーテッドロー](../exercises/long-pull.md) / [ワンハンドロー](../exercises/one-arm-dumbbell-row.md) | [ロングプル](../exercises/long-pull.md)・ニュートラル（Full B）、ロングプル・ワイド（Full C） | 肘の引き方で狙いを変える（→ [角度や握り方](../basics/training-principles.md#角度や握り方は寄せるためのもので決定的な違いではない)） |
| [ダンベル RDL](../exercises/romanian-deadlift.md)（軽め） | [バーベル or DB RDL](../exercises/romanian-deadlift.md)（Full B） | 「軽め」をやめ、3 × 6〜10 @RIR 2 で重さを伸ばす種目になる。フォームが不安なら DB のまま |
| [ショルダープレス](../exercises/shoulder-press.md) | [ラテラルレイズ](../exercises/lateral-raise.md)（Full A・Full C） | 3日版にプレスはない。前部三角筋はインクラインプレスが担い、中部三角筋はレイズで狙う |
| [ヒップリフト](../exercises/glute-bridge.md) | [ヒップスラスト](../exercises/hip-thrust.md)（Full C） | 肩をベンチに乗せ、重さを載せる。1週目はバーだけ、または自重で可動域を確認 |
| [プランク](../exercises/plank.md) / [デッドバグ](../exercises/dead-bug.md) | [ケーブルクランチ](../exercises/cable-crunch.md)（Full A）、[パロフプレス](../exercises/pallof-press.md)（Full C） | 静止から、重さを使って動かす種目へ |

初心者メニューになかった種目は、1週目は軽い重さで動きを覚えることだけを目標にする。

| 新しく入る種目 | 日 | 役割 |
| --- | --- | --- |
| [ケーブル・レッグカール](../exercises/cable-leg-curl.md) / [Nordic ハムストリングカール](../exercises/nordic-hamstring-curl.md) | Full A | 膝を曲げるハム種目。RDL だけでは足りない（→ [種目の選び方](../basics/training-principles.md#ハムストリングス太ももの裏は2種類の動きを必ず入れる)） |
| [レッグエクステンション](../exercises/leg-extension.md) | Full C | 大腿四頭筋のアイソレーション |
| [スタンディング・カーフレイズ](../exercises/standing-calf-raise.md) | Full B | ふくらはぎ |
| [オーバーヘッド・トライセプスエクステンション](../exercises/overhead-triceps-extension.md) | Full B | 上腕三頭筋 |
| [インクライン・ダンベルカール](../exercises/incline-dumbbell-curl.md) | Full B | 上腕二頭筋 |
| [リバースペックデック](../exercises/reverse-pec-deck.md) | Full C | 後部三角筋 |

## 3. 伸びなくなったときの診断フロー

**「2〜3週間、同じフォーム・同じ可動域で、重さも回数も伸びていない」** ときに使う。1〜2回伸びなかっただけなら、まだ何も変えない。

軸は1つ。**一度に変えるのは1つだけ**（→ [基本の考え方 ルール3](../basics/philosophy.md#ルール3一度に変えるのは1つだけ)）。
上から順に確認し、当てはまった項目を **1つだけ直して 1〜2週間** 様子を見る。変わらなければ次へ進む。

```
① 睡眠 → ② 食事 → ③ フォーム・可動域 → ④ 疲労 → ⑤ セット数
```

上にあるものほど、よくある原因で、直すコストが低く、下の項目にも効く。セット数が最後なのは、量を増やしても上乗せは小さく、疲れだけが確実に増えるからである。

| 順 | 確認すること | 当てはまったら | 詳しくは |
| --- | --- | --- | --- |
| ① 睡眠 | 朝起きても疲れが抜けない、寝つきが悪い、安静時心拍が上がったまま、のうち複数が続いていないか | 睡眠を最優先にする。乱れが2日続いたらトレーニング量を落とす | [疲れがたまっているサイン](../basics/recovery.md#疲れがたまっているサイン) |
| ② 食事 | 7日平均の体重が、狙いより速く減っていないか（減量中なら −0.5 kg/週 より速い）。タンパク質を毎日 体重 × 1.6〜2.2 g 取れているか | 減りすぎなら食べる量を 100〜150 kcal 戻す。タンパク質が足りなければ、まずそれだけをそろえる | [体重の読み方](../basics/nutrition.md#体重の読み方)・[まず何をすればいいか](../basics/nutrition.md#2-まず何をすればいいか) |
| ③ フォーム・可動域 | 毎回同じフォーム・同じ可動域・同じベンチ角度でやっているか。回数の上限に届く前に重さを上げていないか | 設定を記録して固定する。重さを一段戻し、全セットで上限に届いてから上げ直す | [ダブルプログレッション](../basics/training-principles.md#ダブルプログレッション)・[やりがちな失敗](../basics/training-principles.md#やりがちな失敗) |
| ④ 疲労 | 同じ種目で2回以上続けて成績が 5〜10% 落ちる、同じ重さが急にきつい、関節の違和感、のうち複数が同時に出ていないか | デロード。5〜7日、セット数を 40〜60% 減らし RIR 3〜4 にする | [デロード](../basics/training-principles.md#デロード) |
| ⑤ セット数 | ①〜④に問題がなく、関節も痛くなく、次回までに回復できているか | その筋肉だけ、A日・B日に1セットずつ足す。順調な筋肉には足さない | [セット数を増やしてもいい条件](../basics/training-principles.md#セット数を増やしてもいい条件) |

- 複数の項目に当てはまっても、直すのは上の1つだけ。全部一度に変えると、何が効いたか分からなくなる
- 伸びる **速さが落ちる** のは停滞ではない。最初の数週間の伸びは神経の適応によるもので、毎週伸び続けるのは最初だけ。見るのは週ごとの差ではなく、[区切りごとの差](#4-12週間後に見るもの)
- 関節の痛みがあるなら、このフローより先にその日はやめる（→ [ルール4：怪我が一番の敵](../basics/philosophy.md#ルール4怪我が一番の敵)）

## 4. 12週間後に見るもの

12週間の終わりに、次の4つを記録して始めたときと比べる。これが [区切りの測定](../basics/philosophy.md#1か月2か月を1つの区切りにする) である。

| 何を | どう比べるか |
| --- | --- |
| 主要種目の重さ | スクワット・プレス・プル・RDL の各1種目。**同じ回数** で何kg挙がるかを、1週目の記録と比べる |
| 7日平均の体重 | 1日の数字ではなく7日平均。狙い（維持 / 減量）どおりに動いたか |
| 腹囲 | 週1回、同じ条件（朝・食前・同じ位置）で測った値 |
| 写真 | 同じ場所・同じ光・同じ姿勢で撮った正面と横 |

週ごとの記録には [週次レビューのテンプレート](../templates/weekly-review.md) が使える。12週分そろえば、区切りの比較はそこから読み取れる。

### 次に何をするか

| 結果 | 次 |
| --- | --- |
| 重さが伸びている | **同じプログラムを続ける**。伸びているものを変える理由はない |
| 伸びが止まり、診断フローも一巡した | 日数を増やせるなら [4日版](../programs/4-day.md)。増やせないなら同じ3日版で、停滞した筋肉だけセット数を見直す |
| 続けられなかった | 日数を減らす。[プログラムの選び方](../programs/README.md) に戻る |

---

## このページのまとめ

1. **3週間後は、続けられた回数と記録で決める。** 同じメニューをもう3週間続けるのも、立派な選択
2. **3日版へは2週間かけて移る。** 1週目は1セット減・RIR 3、2週目はコンパウンドだけ3セットに戻す
3. **伸びなくなったら、睡眠 → 食事 → フォーム → 疲労 → セット数の順。** 直すのは一度に1つ、1〜2週間待つ
4. **12週間後に、重さ・7日平均体重・腹囲・写真を比べる。** 伸びているなら変えない
