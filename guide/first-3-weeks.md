# はじめての3週間：筋トレとは何か、まず何をすればいいか

> **自分に合った重さで、3週間続ける。それだけで人間は大きく変わる。**

このページは、筋トレを始める人が最初に読むページである。
次の順に書いてある。知りたいところから読んでいい。

3. [つまずいたときの考え方](#3-つまずいたときの考え方) … 多くの人がやめてしまう理由と、乗り越え方

## 1. 筋トレとは何か

### 筋肉に負荷をかけて、体を作り変える運動

体は、受けたストレスに耐えられるように自分を作り変える。
筋トレは、筋肉に「少しきつい」負荷をかけて、**「次に同じことが起きても大丈夫なように」** 体を強くする運動である。

```
負荷（トレーニング） → 疲労 → 回復 → 適応（前より少し強くなる）
```

ここから、筋トレで大事なことが3つ分かる。

| 大事なこと | 理由 |
| --- | --- |
| **少しきつい負荷** をかける | 楽すぎると、体が変わる理由がない |
| **休む** | 筋肉は休んでいる間に育つ。毎日やるより週2〜3回の方が伸びる |
| **続ける** | 適応は、やめれば戻る |

もっと詳しい仕組みは [なぜやるのか：体が変わる理論](why.md) にある。最初は上の3つだけ分かっていればいい。

### 最初に伸びるのは筋肉ではなく「神経」

筋力は「筋肉の大きさ」だけで決まるわけではない。**脳と神経が筋肉をうまく使えるか** で大きく変わる。

始めたばかりの体は、

- 一度に動員できる筋線維が少ない
- 動作に関わる筋肉同士のタイミングが合っていない
- 動きそのもの（フォーム）に慣れていない

という状態にある。つまり、**筋肉はあるのに、まだ使い方を知らない** だけ。

だから最初の数週間は、筋肉が大きくなる前に **神経の適応** が進む [[Sale 1988]](../basics/references.md#sale-1988) [[Del Vecchio 2019]](../basics/references.md#del-vecchio-2019)。体が動き方を覚えるにつれて、同じ筋肉でも扱える重さがどんどん増える。
最初の1〜3週間で「先週より重いものが持てた」「回数が増えた」が毎週のように起きるのは、このためである。

### 3週間で体に起きること

| 変化 | 内容 |
| --- | --- |
| 神経の適応 | 同じ種目で扱える重さ・回数がはっきり増える |
| フォームの定着 | 動きが安定し、狙った筋肉に効く感覚が出てくる |
| 習慣化 | 「行くかどうか迷う」が減り、予定の一部になる |
| 睡眠・気分 | 寝つきが良くなる、日中の集中が上がると感じる人が多い |
| 筋肉痛 | 最初の強い筋肉痛が出なくなる |

見た目の変化（筋肉が大きくなる、体型が変わる）は、通常 **8〜12週間** かかる。
しかし **「体が変わり始めた」と自分で分かるのは、3週間あれば十分** である。この手応えが、その先を続ける燃料になる。

## 2. まず何をすればいいか

### 最初の3週間の全体像

| 項目 | 最初の3週間 |
| --- | --- |
| 頻度 | 週2〜3回（例：月・水・金） |
| 種目 | 全身を5種目だけ |
| 時間 | 1回 45〜60分 |
| きつさ | 「あと3〜4回できる」で止める。限界まではやらない |
| 記録 | 種目・重さ・回数をメモする |

### 始める前に決めること

1. **曜日と時間**。「行けたら行く」は行かない。先に予定に入れる
2. **場所**。ジムでも自宅でもいい。続けられる方を選ぶ。自宅なら [ダンベルのみ版](../programs/variants/dumbbell-only.md)・[自重のみ版](../programs/variants/bodyweight-only.md) も使える
3. **記録の方法**。スマホのメモで十分。[記録テンプレート](../templates/README.md) もある

### きつさの基準：RIR

この wiki では、きつさを **RIR（Reps In Reserve：あと何回できたか）** で決める。

| RIR | 意味 | 初心者の使いどころ |
| --- | --- | --- |
| 3〜4 | まだ余裕がある | **最初の1〜2週間はここ** |
| 2 | あと2回できる | 3週目以降の標準 |
| 0 | 限界 | 初心者は使わない |

**「あと3回はできそう」で止める。** 物足りないくらいでいい。
限界までやらない理由は [つまずき2](#重すぎる重量をやってそれだけで疲れ果てる) に書いてある。

> あわせて覚えておく用語：**RM（Repetition Maximum）** は「その重さで何回まで挙げられるか」。10RM = ちょうど10回で限界がくる重さ。

### 重さの決め方

- 1回目は探りでいい。**軽い重さ** から始める。軽すぎて困ることはない
- 目標回数（10〜12回）をやって「あと3〜4回できる」と感じる重さが正解
- 余裕がありすぎたら次のセットで少し上げる。重すぎたら下げる
- 周りの人の重さは見ない。比べる相手は先週の自分だけ

### メニュー

全身を週2〜3回。種目は5つだけ。

| 曜日の例 | 月 | 水 | 金 |
| --- | --- | --- | --- |
| | Day A | Day B | Day A（週3回なら） |

#### Day A

| 種目 | セット × 回数 | RIR |
| --- | --- | --- |
| [レッグプレス](../exercises/leg-press.md) or [ゴブレットスクワット](../exercises/goblet-squat.md) | 2 × 10〜12 | 3〜4 |
| [チェストプレス](../exercises/chest-press-machine.md) or [腕立て伏せ](../exercises/push-up.md)（膝つき可） | 2 × 10〜12 | 3〜4 |
| [ラットプルダウン](../exercises/lat-pulldown.md) | 2 × 10〜12 | 3〜4 |
| [ダンベル RDL](../exercises/romanian-deadlift.md)（軽め） | 2 × 10〜12 | 3〜4 |
| [プランク](../exercises/plank.md) | 2 × 20〜30秒 | 余裕を残す |

#### Day B

| 種目 | セット × 回数 | RIR |
| --- | --- | --- |
| [ゴブレットスクワット](../exercises/goblet-squat.md) | 2 × 10〜12 | 3〜4 |
| [ショルダープレス](../exercises/shoulder-press.md)（マシン or ダンベル） | 2 × 10〜12 | 3〜4 |
| [シーテッドロー](../exercises/long-pull.md) or [ワンハンドロー](../exercises/one-arm-dumbbell-row.md) | 2 × 10〜12 | 3〜4 |
| [ヒップリフト](../exercises/glute-bridge.md) | 2 × 12〜15 | 3〜4 |
| [デッドバグ](../exercises/dead-bug.md) | 2 × 8〜10 / 側 | 余裕を残す |

種目のやり方が分からなければ [種目図鑑](../exercises/README.md) を見る。ジムが怖ければ、マシン種目から始めてもいい。

### 1回の流れ

1. 各種目、軽い重さで1セット動きを慣らしてから本番のセットに入る
2. 5種目を2セットずつ。セットの間は1〜2分休む
3. 最後に **10〜20分の早歩き**（会話ができる程度）→ [有酸素運動](../basics/cardio.md)
4. 帰る前に、やった種目・重さ・回数を記録する

### 3週間の進め方

| 週 | セット数 | RIR | やること |
| --- | --- | --- | --- |
| 1週目 | 各2セット | 3〜4 | 重さを探す。フォームを覚える。記録する |
| 2週目 | 各2セット | 3 | 回数が上限（12回）に届いたら少しだけ重くする |
| 3週目 | 各2〜3セット | 2〜3 | 先週の記録を1回でも超える |

### 3週間後のチェック

- [ ] 1週目の記録と比べて、重さか回数が増えた種目がある
- [ ] フォームが安定してきた
- [ ] 筋肉痛がほとんど出なくなった
- [ ] トレーニングの日が「予定」になった

1つでも当てはまれば、あなたの体はもう変わり始めている。

### 3週間が終わったら

次に読むのは [3週間が終わったら：次の12週間](next-12-weeks.md)。続けられた回数と記録の伸びで、同じメニューを続けるか、[3日版](../programs/3-day.md) へ移るかを決める。3日版への移り方と、伸びなくなったときの見直し方もそこに書いてある。
同じメニューをもう3週間続けてもいい。続けられていること自体が、一番の成果である。

## 3. つまずいたときの考え方

筋トレを始めた人の多くは、最初の数週間でやめてしまう。理由はだいたい次の3つに集約される。

### 重量が上がらなくて絶望する

#### よくある状況

- ジムに行ってみたら、周りの人が扱っている重さの半分も持ち上がらない
- ベンチプレスでバーだけ（20kg）でもきつい
- SNS で見た「初心者向けメニュー」の重量が全然できない

**これは全員が通る道である。** 今ジムで重いものを挙げている人も、最初は同じだった。
上がらないのは才能の問題ではなく、[神経がまだ慣れていない](#最初に伸びるのは筋肉ではなく神経) だけ。

#### どう考えればいいか

| やりがちなこと | 代わりにやること |
| --- | --- |
| 他人の重量と比べる | **先週の自分** と比べる |
| 恥ずかしいので重めに設定する | 軽い重量から始める。軽すぎて困ることはない |
| 上がらない = 才能がない | 上がらない = まだ神経が慣れていない |
| 1回目の結果で判断する | 3週間の推移で判断する |

**記録をつけると、伸びが目に見える。** 初日の記録は、3週間後に自分を励ます材料になる。

### 重すぎる重量をやって、それだけで疲れ果てる

#### よくある状況

- 「筋トレはきつくないと意味がない」と思って、最初から限界の重さでやる
- 1種目目で全力を出して、2種目目以降はフラフラ
- 翌日以降ひどい筋肉痛で動けず、次のトレーニングまで間が空く
- そのままフェードアウト

#### 初心者は限界まで追い込まなくても十分に伸びる

**限界（1RM）に近い重さ** を扱うほど、1回ごとの疲労は大きくなる。神経・関節・気持ちの消耗も大きい。
初心者がいきなりこれをやると、**刺激よりも疲労の方が大きくなる。**

筋肉にとっての刺激は「限界まで行ったか」ではなく、「**限界の少し手前まで、十分な回数をこなしたか**」の方が重要である。

#### 物足りないくらいでやめるべき理由

1. **フォームを覚える時間** になる。重すぎると崩れたフォームを覚えてしまう
2. **翌日も動ける**。筋肉痛が軽ければ、次のトレーニングに行ける
3. **怪我をしない**。最初の数週間は関節や腱が筋肉より遅れて適応する
4. **嫌にならない**。「きつかった」より「またやれそう」で終わる方が続く

> 筋肉痛の強さは、効果の大きさを表していない。新しい動きをすれば筋肉痛は出るし、慣れれば出なくなる。それでも筋肉は育つ。

### 3週間続かない

- **やることを減らす**。最初は1回 4〜5種目、45〜60分で十分
- **曜日と時間を固定する**。「行けたら行く」は行かない
- **やる気に頼らない**。疲れている日は、軽くして行くだけでいい（ゼロにしない）
- **1回休んでもやめない**。休んだ次の回に、何事もなかったように戻る

### その他のつまずき

| つまずき | 考え方 |
| --- | --- |
| ジムが怖い・恥ずかしい | 他人はあなたを見ていない。空いている時間帯を選ぶ。マシン種目から始めるのもあり |
| 何キロから始めればいいか分からない | [重さの決め方](#重さの決め方) を見る。最初の1回は探りでいい |
| 始めたら体重が増えた | 筋肉ではなく水分。新しい刺激で筋肉が水を抱える。1〜2週間で落ち着く |
| 種目が多すぎて覚えられない | [上の5種目](#メニュー) だけでいい |
| 毎日やりたくなる | 筋肉は休んでいる間に育つ。最初は週2〜3回 |
| SNS の人と比べて落ち込む | 比べる相手は過去の自分だけ |
| 休むことに罪悪感がある | 休養はトレーニングの一部 |

## このページのまとめ

1. **筋トレは「少しきつい負荷 → 休む → 強くなる」の繰り返し。** 最初に伸びるのは筋肉ではなく神経
2. **週2〜3回、5種目、「あと3回できる」で止める。** それだけで3週間後には体が変わり始める
3. **最初に重量が上がらないのは当たり前。** 比べる相手は先週の自分だけ
