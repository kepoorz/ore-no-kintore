# 04. 睡眠・回復

筋肉はトレーニング中ではなく **回復中に** 成長する。
睡眠不足は減量効率も落とす（食欲ホルモンの乱れ、除脂肪の減少、コルチゾールによる水分保持）。**減量を止める最大のリスク要因。**

## 基本認識

- 筋トレをしている人が慢性的に眠れないのは「普通」ではない。運動していれば本来、寝つきは早く深い睡眠も増える
- 「疲れているのに眠くならない」= トレーニング量に回復が追いついていないサイン（交感神経が優位のまま切り替わらない）
- トレーニング直後のコルチゾール上昇は正常。問題は慢性的に高い状態

## アラート条件（オーバーストレスのサイン）

複数当てはまったら回復不足と判断する。

- [ ] 起床時に疲れが抜けていない / 寝つき・睡眠の質が悪化
- [ ] 安静時心拍が上がったまま戻らない
- [ ] パフォーマンスが数セッション連続で落ちる
- [ ] 風邪をひきやすい、気分の落ち込み、食欲の異常
- [ ] 全身の慢性的な筋肉痛、皮膚トラブル

**対処はサプリではなく**：睡眠優先 / 有酸素を一時的に減らす / カロリー赤字を緩める。

## 判断ルール

```
睡眠の乱れ 1日      → 誤差
睡眠の乱れ 2日連続  → 量を落とす（翌日を完全オフ 等）
慢性的な筋肉痛      → 通常 2〜3週で適応して収まる
  量を落としても 3週以上続く / 睡眠が改善しない → 食事量そのものの不足を疑う
デロード・回復優先期間 → カロリー赤字を −400 → −250 程度に緩める
```

## 眠れないときの対策（優先順）

1. **デロード**：筋トレの重量・セット数を約7割に落とすか、2〜3日完全休養。有酸素も強度・時間を下げる。回復日は RPE3 以下を厳守。1週間休んでも筋力・筋量は落ちない
2. **夕食に炭水化物を戻す**：炊いた米 80〜100g。昼を少し減らして夜に回す。夜の炭水化物不足は トリプトファン → セロトニン → メラトニン の流れを弱め、寝つきを直接悪くする
3. **トレーニングは就寝3時間前までに終える**
4. **体温を下げる**：就寝1〜2時間前にぬるめのシャワー（風呂は就寝90分前まで）、寝室は涼しく（エアコン 24〜26℃）。暑い地域では深部体温が下がりにくい
5. **カフェインは昼まで**
6. **就寝前にマグネシウム**（グリシン酸 or クエン酸、200〜300mg）
7. **筋肉痛には** 完全休養より 10〜15分の散歩や軽いストレッチで血流を

## インシデント事例

> **事象**：筋トレ過多で全身筋肉痛 + 寝つきの悪化。
> **観察**：夕食にバーガー + ヨーグルトを食べた日は 21時〜8時まで眠れた。
> **原因の切り分け**：効いたのはカロリー量より **夕食の炭水化物**。同じ効果は米100g + 鶏むねでも得られる。
> **対策**：夕食の炭水化物を固定で確保。運動量が多い日の炭水化物の増量分は夕食に寄せる。
