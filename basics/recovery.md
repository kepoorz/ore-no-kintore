# 睡眠と回復

> **筋肉はトレーニング中ではなく、回復中に成長する。**
> どんなに良いメニューをこなしても、寝られていなければ体は育たない。

このページで分かること：

- なぜ睡眠がそれほど大事なのか
- 疲れがたまっているときに出るサイン
- サインが出たときにどう動くか
- 眠れないときに試すこと（効きやすい順）

---

## なぜ睡眠が大事なのか

トレーニングは筋肉に「刺激」を与えるだけで、筋肉が実際に太く・強くなるのはその後の休んでいる時間である。
その回復の中心にあるのが睡眠だ。

睡眠不足は、筋肉だけでなく **減量の効率も落とす。**

| 睡眠不足で起きること | 結果 |
| --- | --- |
| 食欲に関わるホルモンが乱れる | お腹が空きやすくなり、食事管理が難しくなる |
| 除脂肪（脂肪以外の体重＝主に筋肉）が減りやすくなる | 痩せても筋肉ばかり落ちる [[Nedeltcheva 2010]](references.md#nedeltcheva-2010) |
| コルチゾール（ストレスホルモン）で体に水分がたまる | 体重が落ちにくく見える |

**睡眠不足は、減量を止めてしまう一番大きな原因である。**

---

## まず知っておきたいこと

- **筋トレをしているのに、いつも眠れないのは「普通」ではない。** 運動していれば、本来は寝つきが早くなり、深い睡眠も増える
- **「疲れているのに眠くならない」は、トレーニング量に回復が追いついていないサイン。** 体が興奮モード（交感神経が優位な状態）のまま、休むモードに切り替わらなくなっている
- **トレーニング直後にコルチゾールが上がるのは正常。** 問題になるのは、それがずっと高いままの状態

---

## 疲れがたまっているサイン

次のチェックリストのうち、**複数当てはまったら回復が足りていない** と考える。

- [ ] 朝起きても疲れが抜けていない / 寝つきや眠りの質が悪くなった
- [ ] 安静時心拍（朝起きてすぐの心拍数）が上がったまま戻らない
- [ ] トレーニングの記録が、数回続けて落ちている
- [ ] 風邪をひきやすい、気分が落ち込む、食欲がおかしい
- [ ] 全身の筋肉痛がずっと続いている、肌荒れなどが出る

> **対処はサプリではない。**
> やることは次の3つ：**睡眠を最優先にする / 有酸素運動を一時的に減らす / カロリーを減らす幅（カロリー赤字）をゆるめる。**

---

## サインが出たときの目安

状況ごとに、どこまで様子を見て、いつ動くかの目安をまとめる。

| 状況 | どうするか |
| --- | --- |
| 睡眠が乱れたのが1日だけ | よくあること。気にしなくていい |
| 睡眠の乱れが2日続いた | トレーニング量を落とす（翌日を完全に休みにする など） |
| 全身の筋肉痛がずっと続く | ふつうは2〜3週間で体が慣れて収まる |
| 量を落としても筋肉痛が3週間以上続く / 睡眠が良くならない | そもそも食べる量が足りていない可能性を疑う |
| デロード中・回復を優先している期間 | カロリー赤字を −400 kcal → −250 kcal 程度にゆるめる |

> **デロード** とは、疲れがたまったときに入れる「軽めの期間」のこと（→ [筋トレの原則](training-principles.md#デロード)）。

## 眠れないときの対策（効きやすい順）

上から順に試す。全部を一度にやる必要はない（→ [基本の考え方](philosophy.md) の「一度に変えるのは1つだけ」）。

| 順番 | 対策 | 具体的にやること |
| --- | --- | --- |
| 1 | **デロードする** | 筋トレの重さ・セット数を約7割に落とすか、2〜3日完全に休む。有酸素運動もきつさ・時間を下げる |
| 2 | **夕食に炭水化物を戻す** | 炊いたご飯 80〜100g。昼を少し減らして、その分を夜に回す |
| 3 | **トレーニングは寝る3時間前までに終える** | 夜遅いトレーニングは体が興奮したままになりやすい |
| 4 | **体温を下げる** | 寝る1〜2時間前にぬるめのシャワー（湯船なら寝る90分前まで）。寝室は涼しく（エアコン 24〜26℃） |
| 5 | **カフェインは昼まで** | コーヒー・エナジードリンクは午後に飲まない |
| 6 | **寝る前にマグネシウム** | グリシン酸マグネシウム or クエン酸マグネシウム、200〜300mg |
| 7 | **筋肉痛には軽く動く** | 完全に休むより、10〜15分の散歩や軽いストレッチで血流を良くする |

各対策の補足：

- **デロード**：回復日の運動は RPE3 以下を必ず守る。RPE は「主観的なきつさ」を0〜10で表したもので、3は「楽に会話できる程度」。**1週間休んでも、筋力・筋肉量は落ちない。** 休むことを怖がらなくていい
- **夕食の炭水化物**：夜に炭水化物が足りないと、トリプトファン → セロトニン → メラトニン（眠りを促すホルモン）という流れが弱まり、**寝つきが直接悪くなる**
- **体温**：人は体の内側の温度（深部体温）が下がるときに眠くなる。暑い地域では深部体温が下がりにくいので、特に意識する

## やりがちな失敗

| 失敗 | なぜダメか | 代わりにやること |
| --- | --- | --- |
| 眠れないのに同じ量のトレーニングを続ける | 回復が追いつかず、どんどん疲れがたまる | 2日続いたら量を落とす。デロードを入れる |
| 減量中、夜の炭水化物をゼロにする | 寝つきが悪くなり、結果的に減量も止まる | 夕食にご飯 80〜100g を確保する |
| 疲れをサプリでなんとかしようとする | 根本の原因（睡眠・量・食事）が変わらない | 睡眠優先・有酸素を減らす・カロリー赤字をゆるめる |
| 休むと筋肉が落ちると思って休めない | 1週間休んでも筋力・筋肉量は落ちない | 疲れのサインが出たら、ためらわず休む |
| 夜遅くにトレーニングして、すぐ寝ようとする | 体が興奮したままで寝つけない | 寝る3時間前までに終える |

### 実際にあった例

> **何が起きたか**：トレーニングのやりすぎで、全身筋肉痛 + 寝つきが悪くなった。
> **気づいたこと**：夕食にハンバーガー + ヨーグルトを食べた日は、21時〜8時までぐっすり眠れた。
> **原因を絞り込むと**：効いたのはカロリーの多さではなく、**夕食の炭水化物** だった。同じ効果は、ご飯100g + 鶏むね肉でも得られる。
> **その後の対策**：夕食の炭水化物を毎日決まった量で確保する。運動量が多い日に炭水化物を増やすなら、その分は夕食に回す。

---

## まとめ

- **筋肉は寝ている間に育つ。睡眠不足は減量も止める**
- **「疲れているのに眠れない」は回復不足のサイン**
- **睡眠の乱れが2日続いたら、トレーニング量を落とす**
- **眠れないときは、まずデロードと夕食の炭水化物**
- **1週間休んでも筋肉は落ちない。休むことを怖がらない**
