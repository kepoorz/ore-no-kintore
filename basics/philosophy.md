# 00. 基本の考え方：長く続けて、記録して、少しずつ直す

> **体づくりは短期決戦ではなく、何年も続く長期戦である。**
> 大事なのは「一番いいメニュー」を探すことではなく、「続けられるやり方」を見つけて、少しずつ直していくこと。

このページは、このwikiのすべてのページの土台になる考え方をまとめたものである。
細かい理論は後回しでいい。まずはここに書いてある5つのルールだけ覚えておけば、大きく道を外れることはない。

---

## 5つの基本ルール

### ルール1：完璧より、続けること

| よくある考え | このwikiの考え |
| --- | --- |
| 最強のメニューを見つけてから始めたい | 70点のメニューでいいから、今日始める |
| きついメニューほど効果がある | 続かないメニューは、効果ゼロと同じ |
| 1日サボったら台無し | 1日休んでも何も失われない。やめなければいい |

完璧なメニューを3週間でやめるより、**ほどほどのメニューを3年続ける方が、体はずっと大きく変わる。**
迷ったら「これなら続けられるか？」で選ぶ。

### ルール2：記録しないと、伸びているか分からない

筋トレの成果は、1日や1週間ではほとんど目に見えない。
だから **数字で記録する。** 記録があれば「先月より5kg重く挙げられるようになった」と分かり、それが続ける力になる。

最初は次の3つだけでいい。

- その日にやった **種目・重さ・回数**
- 毎朝の **体重**
- **何時間寝たか**

慣れてきたら記録する項目を増やしていく（→ [記録しておくと役立つもの](#記録しておくと役立つもの)）。

### ルール3：一度に変えるのは1つだけ

伸び悩んだとき、食事・メニュー・睡眠を一気に全部変えたくなる。
しかしそれをやると、**うまくいっても、何が効いたのか分からない。** 悪くなったときも原因が分からない。

> 例：「最近重量が伸びない」
> → まず睡眠を30分増やして2週間様子を見る
> → 変わらなければ、次は食事を見直す

1つ変えたら、少なくとも1〜2週間はそのまま様子を見る。

### ルール4：怪我が一番の敵

怪我をすると数週間〜数か月トレーニングができなくなり、それまで積み上げたものが落ちていく。
**どんなに頑張るより、怪我をしないことの方が成果に直結する。**

- 重さを上げるためにフォームを崩さない
- 関節（肩・肘・膝・腰）に痛みが出たら、その日はやめる
- 眠い・だるい日は軽めにする

### ルール5：毎回考えなくていい仕組みを作る

「今日は何をやろう」「何を食べよう」と毎回悩むと、それだけで疲れて続かなくなる。

- トレーニングする曜日と時間を決めておく
- やるメニューを決めておく（→ [プログラム集](../programs/README.md)）
- 朝ごはんなど、毎日同じでいいものは固定する

**決めておけば、あとは淡々とこなすだけになる。**

## 1か月〜2か月を1つの区切りにする

体の変化はゆっくりなので、**4〜8週間を1つの区切り** として、その単位で振り返る。

```
① 計画を立てる（どのメニューを、何週間やるか決める）
    ↓
② やる（トレーニングして、記録をつける）
    ↓
③ 週に1回ふりかえる（記録を見て、伸びているか確認する）
    ↓
④ 調整する（重さ・セット数・食事を少しだけ変える）
    ↓
  ①に戻る
```

| 用語 | 意味 |
| --- | --- |
| ブロック | 4〜8週間の1区切り。同じメニューを続ける期間 |
| 区切りの測定 | ブロックの最後に、体重・主な種目の重さ・体の写真を記録して前回と比べる |
| デロード | 疲れがたまったときに入れる「軽めの週」。セット数をいつもの半分くらいに減らす。日程を決めて入れるのではなく、疲れのサインが出たら入れる（→ [筋トレの原則](training-principles.md#デロード)） |

週に1回のふりかえりには [週次レビューのテンプレート](../templates/weekly-review.md) が使える。

## 記録しておくと役立つもの

最初から全部やる必要はない。上から順に、できるものから始めればいい。

| 何を記録するか | いつ | 何がわかるか |
| --- | --- | --- |
| 種目・重さ・回数 | トレーニングのたび | 先週より強くなっているか |
| 体重 | 毎朝（起きてトイレの後） | 太っているか・痩せているかの流れ |
| 睡眠時間 | 毎日 | 回復できているか。**伸びない原因の第一候補** |
| お腹まわりのサイズ・体の写真 | 週に1回 | 体重だけでは分からない見た目の変化 |
| 朝の心拍数（安静時心拍） | 毎朝 | 体力がついてきたか・疲れがたまっていないか |
| 部位ごとの週のセット数 | 週に1回 | やりすぎ・やらなさすぎの確認 |
| 有酸素運動の時間ときつさ | やったとき | 食事量の調整・疲れの管理 |

> **体重は毎日バラつくものである。**
> 水分や食べた量だけで1〜2kgは平気で上下する。1日の数字で一喜一憂せず、**1週間の平均** で増えたか減ったかを見る。

記録用のテンプレートは [templates/](../templates/README.md) にある。

## やりがちな失敗

| 失敗 | なぜダメか | 代わりにやること |
| --- | --- | --- |
| 毎週メニューを変える | 効いているか判断する前に変わってしまう | 最低4週間は同じメニューを続ける |
| 記録をつけない | 伸びているのか停滞しているのか、感覚では分からない | スマホのメモでもいいから数字を残す |
| 睡眠を削ってジムに行く | 寝ている間に筋肉は育つ。睡眠不足だと伸びない | 寝不足の日は休むか、軽めにする |
| 上級者のメニューをそのまま真似する | 量が多すぎて回復が追いつかない | 自分の段階に合ったメニューから始める（→ [はじめての3週間](../guide/first-3-weeks.md)） |
| 一度に全部変える | 何が効いたか分からなくなる | 1つずつ変える |

---

## まとめ

- **続けることが最優先**
- **数字で記録する**
- **変えるのは1つずつ**
- **怪我をしない**
- **悩まなくていい仕組みを作る**

この5つを守っていれば、メニューの細かい違いはあとからいくらでも直せる。
