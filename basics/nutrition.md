# 01. 食べ物の考え方

## 優先順位

上から順に効く。下を気にするのは上が揃ってから。

1. **週単位のカロリー収支**（体重の増減を決める）
2. **タンパク質量**（筋肉の材料。日によらず固定）
3. **炭水化物の量とタイミング**（運動量・睡眠に合わせて調整する変数）
4. **食事の質**（野菜・果物・発酵食品）
5. **サプリメント**

## Step 1. その日の目標摂取カロリー（計算式）

運動量から日ごとに維持カロリーを推定する。

```
維持カロリー = BASE + 筋トレ量 × 0.06 + 有酸素負荷 × 1.3
目標摂取     = 維持カロリー − 400

  BASE     = 1,900   # 自分の基礎部分（実測から較正）
  筋トレ量 = Σ(重量kg × 回数)
  有酸素負荷 = 時間(分) × RPE(0〜10)
```

### BASE の較正方法

1. 体重がほぼ横ばいだった1週間の 摂取kcal・筋トレ量・有酸素負荷 を集計
2. 運動分を差し引いて BASE を逆算
3. Mifflin-St Jeor 式（BMR × 1.2）と比較して大きくズレていないか確認

> 実例：体重横ばいの週から逆算した BASE ≒ 1,903 kcal、Mifflin-St Jeor × 1.2 ≒ 1,938 kcal。ほぼ一致したので 1,900 を採用。

### 目安表

| 日のタイプ | 目標摂取 |
| --- | --- |
| 完全休養日 | 約 1,500 kcal |
| 軽い有酸素のみ | 約 1,760 kcal |
| 筋トレ + 有酸素20分 | 約 1,870 kcal |
| 筋トレ + 有酸素45分（RPE6） | 約 2,090 kcal |
| ロング有酸素90分（RPE6） | 約 2,200 kcal |

- 精度は ±15% 程度。**日単位で詰めず、週平均で見る**
- マシンの消費カロリー表示は過大なので使わない（計算式との二重計上にもなる）

## Step 2. マクロ栄養素

| 栄養素 | ルール |
| --- | --- |
| タンパク質 | **固定**：体重 × 1.8〜2.0 g（自分は 130〜140g） |
| 脂質 | 50〜60g を確保 |
| 炭水化物 | **ここで増減させる**。運動量が多い日ほど増やし、増やす分は夕食に寄せる |

- 炭水化物は抜かない。量とタイミングで管理する
- 過去に痩せられなかった主因は「米の食べすぎ」だった → 炊いた状態で計量する

## Step 3. 固定献立（デフォルト食）

意思決定を減らすため、献立はほぼ固定。現地で安く手に入る食材で組む。

**中心食材**：鶏むね肉、木綿豆腐、卵、テンペ、きのこ、ブロッコリー、ミニトマト、バナナ、キウイ、オリーブオイル、キムチ、ヨーグルト

| | 通常期 | 負荷期（運動量が多い週） |
| --- | --- | --- |
| ご飯（炊いた状態） | 朝150g / 昼150g / 夜100g | 朝のみ200g |
| アドオン | — | 朝：トレ前バナナ / 昼：ゆで卵 or テンペ / 夜：就寝前ヨーグルト |
| kcal | 約 1,780〜1,820 | 約 2,040〜2,090 |
| P / F / C | 147〜156 / 52〜53 / 183〜195 g | 158 / 57 / 229 g |

- 負荷期で増えるのは **ほぼ炭水化物だけ**
- 鶏むねのグラム表記は **調理前の重量**
- **フォールバック（最低ライン）**：約1,500kcal（米・卵・豆腐・プロテイン・アーモンド）。**1,500kcal は絶対に割らない**

## Step 4. 減量の週次基準

| 項目 | 基準 |
| --- | --- |
| 目標ペース | 7日平均体重で −0.3〜−0.5 kg/週（体重の 0.4〜0.7%） |
| 週平均摂取 | 1,900〜2,000 kcal |
| 会食 | 週1回まで |
| 酒・どか食い | 正直に記録し、週平均で吸収させる |
| 週間負荷の増加 | 前週比 +10% 以内 |

### 調整ルール（制御ループ）

```
if 7日平均が 2週連続で横ばい:
    BASE -= 100            # 全日 −100kcal
    # または 有酸素負荷 +300/週
elif 減少ペース > 0.6 kg/週:
    BASE += 100〜150       # 筋肉量を守るため戻す
if 睡眠・回復が悪い:
    赤字を −350〜400 に留める
if デロード週:
    赤字を −250 程度に緩める

# 2〜3週ごとに BASE を再較正する
```

## 体重の読み方

体重計の値 = 脂肪 + 水分 + グリコーゲン + 胃腸の内容物。**ノイズの大きいセンサー**として扱う。

- 数日〜1週間の体重増は筋肥大では説明できない（筋肉の増加は月 0.2〜0.5kg 程度）
- 主なノイズ源：新しい筋トレ刺激、アルコール、塩分、高炭水化物（グリコーゲン1g につき水約3g）、睡眠不足
- 会食が続くと、脂肪減少が水分で相殺されて見えることがある
- 横ばいが続いた後に一気に落ちる（いわゆるウーシュ効果）こともある。慌てない

**評価指標**：7日平均体重 + 週1回のウエスト実測 + 同条件の週次写真。会食のない 7〜10日を1ブロックとして比較する。

## カロリー赤字についての誤解

| 主張 | 判定 |
| --- | --- |
| 食べないと脂肪が落ちない（飢餓モード） | ✕ 赤字が深いほど脂肪は落ちる |
| 赤字だと筋肉は増えない | △ ほぼ正しい。ただし目標が「維持」ならタンパク質 + 筋トレで守れる |
| 深い赤字のコストは？ | 落ちた体重の中身が悪くなる（除脂肪が削られる）、回復・睡眠が崩れて継続できなくなる |

- 寒さを感じやすくなるのは、赤字が効いているサインと解釈している

## トレーニング前後の補給

| 状況 | 方針 |
| --- | --- |
| 朝の高負荷セッション | 空腹で行わない。バナナ1本程度の炭水化物を先に入れる |
| 低強度・40分未満の有酸素 | 空腹でも大きな問題はない |
| やむを得ず空腹でトレーニングした | 終了後 30〜60分以内にタンパク質中心の食事 |
| 高強度トレーニングの日 | 就寝前にタンパク質（ヨーグルト等） |

- 朝の順序：**朝食 → 筋トレ → 有酸素**。筋トレは常に有酸素より先
- 空腹トレの短期的な脂肪酸化より、筋分解と質の低下のデメリットが大きい。大事なのは週単位の収支
- 筋肉痛の有無でタンパク質を足すのではなく、1日の総量を満たすことを優先

## サプリメント

| サプリ | 判断 |
| --- | --- |
| プロテイン | 食事で足りない分を補う食品扱い |
| BCAA | 1日の総タンパク質が足りていれば不要。手持ちは「ゼロカロリーの電解質ドリンク」として長時間セッションで使う |
| マグネシウム | 高温多湿で大量に汗をかく環境では不足しやすい。就寝前にグリシン酸 or クエン酸マグネシウム 200〜300mg から。酸化マグネシウムは吸収が悪いので避ける |
