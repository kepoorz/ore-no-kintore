# 01. 食べ物の考え方

> **体重を決めるのは「1週間でどれだけ食べて、どれだけ使ったか」である。**
> 1日ごとの細かい数字より、週単位でざっくり合っていればいい。

このページで分かること：

- 何から気にすればいいか（優先順位）
- その日に何kcal食べればいいか（計算のしかた）
- タンパク質・脂質・炭水化物の決め方
- 減量がうまく進んでいるかの見方と、進まないときの直し方

---

## 優先順位

上から順に効く。**下を気にするのは、上がそろってから。**

1. **1週間のカロリーの出入り**（体重が増えるか減るかは、ほぼこれで決まる）
2. **タンパク質の量**（筋肉の材料。毎日同じ量を取る）
3. **炭水化物の量とタイミング**（運動量や睡眠に合わせて増減させる）
4. **食事の質**（野菜・果物・発酵食品）
5. **サプリメント**

| よくある考え | このwikiの考え |
| --- | --- |
| まずは良いサプリを買う | サプリは5番目。まずカロリーとタンパク質 |
| 炭水化物を抜けば痩せる | 抜かない。**量とタイミング** で調整する |
| 毎日きっちり同じカロリーにする | 日によって変えていい。**週の平均** が合っていればいい |

---

## Step 1. その日に食べる量を決める

運動した日はたくさん使うので、多めに食べる。休んだ日は少なめにする。
そのための計算式が次のものである。

```
体重が変わらない量 = BASE + 筋トレ量 × 0.06 + 有酸素の負荷 × 1.3
その日に食べる量   = 体重が変わらない量 − 400

  BASE        = 1,900   # 運動しなくても毎日使う分（自分の実際の記録から割り出す）
  筋トレ量     = (重さkg × 回数) をその日の全セット分足したもの
  有酸素の負荷 = 時間(分) × RPE(0〜10)
```

- **BASE**：運動以外で1日に使うカロリーの目安。人によって違うので、自分の記録から決める（やり方は下）
- **RPE**：その運動の「きつさ」を自分で0〜10で付けた点数。0が何もしていない状態、10が限界
- **−400**：毎日400kcalずつ少なめに食べて、少しずつ脂肪を落とす

### 計算してみる

例：筋トレをして、そのあと有酸素を20分やった日。

1. 筋トレ量を出す。たとえば 60kg × 10回 × 3セット = 1,800。ほかの種目も足して、合計 **4,000** だったとする
2. 4,000 × 0.06 = **240 kcal**
3. 有酸素の負荷を出す。20分 × RPE 5 = 100。100 × 1.3 = **130 kcal**
4. 体重が変わらない量 = 1,900 + 240 + 130 = **2,270 kcal**
5. その日に食べる量 = 2,270 − 400 = **約 1,870 kcal**

### BASE の決め方

BASE は、自分の実際の記録から逆算して決める。

1. 体重がほぼ変わらなかった1週間を選び、その週の「食べたkcal」「筋トレ量」「有酸素の負荷」を集計する
2. 食べた量から運動で使った分を引くと、BASE が出る
3. Mifflin-St Jeor 式（身長・体重・年齢から「何もしなくても使うカロリー」を出す有名な計算式）の値 × 1.2 と比べて、大きくズレていないか確認する

> 実例：体重が変わらなかった週から逆算した BASE は約 1,903 kcal。Mifflin-St Jeor 式 × 1.2 は約 1,938 kcal。ほぼ同じだったので 1,900 にした。

### 目安表

| 日のタイプ | その日に食べる量 |
| --- | --- |
| 完全に休んだ日 | 約 1,500 kcal |
| 軽い有酸素だけ | 約 1,760 kcal |
| 筋トレ + 有酸素20分 | 約 1,870 kcal |
| 筋トレ + 有酸素45分（RPE 6） | 約 2,090 kcal |
| 長めの有酸素90分（RPE 6） | 約 2,200 kcal |

> **この計算はだいたい ±15% くらいズレる。**
> 1日ごとにきっちり合わせようとせず、**1週間の平均** で見る。

- ランニングマシンやバイクに表示される消費カロリーは多めに出るので使わない。計算式にもう入っているので、足すと二重に数えることにもなる

## Step 2. 栄養素の割り振り（PFC）

カロリーの中身は、**タンパク質（P）・脂質（F）・炭水化物（C）** の3つに分けて考える。この3つを「マクロ栄養素」、頭文字をとって「PFC」と呼ぶ。

| 栄養素 | 決め方 |
| --- | --- |
| タンパク質（P） | **毎日固定**：体重 × 1.8〜2.0 g（自分は 130〜140g） |
| 脂質（F） | 50〜60g は取る |
| 炭水化物（C） | **ここで量を調整する**。運動が多い日ほど増やし、増やした分は夕食に回す |

- 炭水化物は抜かない。**量とタイミング** で調整する
- 前に痩せられなかった一番の原因は「ご飯の食べすぎ」だった → ご飯は **炊いた状態で量る**

---

## Step 3. いつもの献立を決めておく

毎食「何を食べよう」と悩むと疲れるので、献立はほぼ固定にしている。近所で安く手に入る食材で組む。

**よく使う食材**：鶏むね肉、木綿豆腐、卵、テンペ（大豆の発酵食品）、きのこ、ブロッコリー、ミニトマト、バナナ、キウイ、オリーブオイル、キムチ、ヨーグルト

| | ふだんの週 | 運動が多い週 |
| --- | --- | --- |
| ご飯（炊いた状態） | 朝150g / 昼150g / 夜100g | 朝だけ200g |
| 追加するもの | なし | 朝：トレーニング前にバナナ / 昼：ゆで卵 or テンペ / 夜：寝る前にヨーグルト |
| kcal | 約 1,780〜1,820 | 約 2,040〜2,090 |
| P / F / C | 147〜156 / 52〜53 / 183〜195 g | 158 / 57 / 229 g |

- 運動が多い週に増えるのは **ほぼ炭水化物だけ**
- 鶏むね肉のグラム数は **焼く・ゆでる前の重さ**
- **最低ライン**：どうしても準備できない日は約1,500kcal（ご飯・卵・豆腐・プロテイン・アーモンド）。**1,500kcal は絶対に下回らない**

## Step 4. 減量の1週間ごとの目安

| 項目 | 目安 |
| --- | --- |
| 減らすペース | 7日平均の体重で −0.3〜−0.5 kg/週（体重の 0.4〜0.7%） |
| 1週間の平均摂取 | 1,900〜2,000 kcal |
| 外食・飲み会 | 週1回まで |
| お酒・食べすぎ | 正直に記録して、週の平均の中で埋め合わせる |
| 運動量の増やし方 | 前の週の +10% まで |

### 進まないとき・進みすぎるときの直し方

| こうなったら | こうする |
| --- | --- |
| 7日平均の体重が **2週続けて** 変わらない | BASE を −100（毎日100kcal減る）。または有酸素の負荷を週 +300 |
| 1週間で **0.6kg より多く** 減っている | BASE を +100〜150。減りすぎは筋肉も落ちるので戻す |
| よく眠れない・疲れが抜けない | 毎日の不足分を −350〜400 までにとどめる |
| デロード週（疲れを抜くための軽めの週） | 不足分を −250 くらいにゆるめる |

**2〜3週ごとに、BASE を自分の記録から決め直す。**

## 体重の読み方

体重計の数字には、脂肪だけでなく **水分・グリコーゲン（筋肉や肝臓にためた糖）・お腹の中の食べ物** も入っている。
だから **毎日かなりブレるもの** として扱う。

- 数日〜1週間で体重が増えても、それは筋肉ではない（筋肉が増えるのは月 0.2〜0.5kg くらい）
- ブレる主な原因：新しい筋トレを始めた、お酒、塩分、炭水化物を多く食べた（グリコーゲン1gにつき水が約3gくっつく）、寝不足
- 外食が続くと、脂肪は減っているのに水分で増えて見えることがある
- しばらく変わらなかった体重が、ある日急にストンと落ちることもある（「ウーシュ効果」と呼ばれる）。慌てない

> **進み具合は、次の3つで見る。**
> 7日平均の体重 + 週1回のお腹まわりのサイズ + 同じ条件で撮る週1回の写真。
> 外食のない7〜10日間を1つのまとまりとして比べる。

## カロリー不足についての誤解

| よくある考え | このwikiの考え |
| --- | --- |
| 食べないと逆に痩せない（飢餓モード） | ✕ 不足が大きいほど脂肪は落ちる |
| 食べる量が足りないと筋肉は増えない | △ ほぼ正しい。ただし「今の筋肉を守る」なら、タンパク質 + 筋トレで守れる |
| 大きく減らすと何がまずい？ | 落ちる中身が悪くなる（筋肉も削られる）。回復や睡眠が崩れて続かなくなる |

- 寒さを感じやすくなるのは、ちゃんとカロリーが不足しているサインだと考えている

## トレーニング前後の食事

| 状況 | どうするか |
| --- | --- |
| 朝にきついトレーニングをする | 空腹のままやらない。バナナ1本くらいの炭水化物を先に食べる |
| 軽い有酸素を40分未満 | 空腹でも大きな問題はない |
| 仕方なく空腹でトレーニングした | 終わってから30〜60分以内に、タンパク質を中心に食べる |
| きついトレーニングをした日 | 寝る前にタンパク質（ヨーグルトなど） |

- 朝の順番は **朝食 → 筋トレ → 有酸素**。筋トレはいつも有酸素より先
- 空腹でやると脂肪が少し燃えやすくなるが、筋肉が分解されたりトレーニングの質が落ちたりする方が損が大きい。大事なのは **1週間の出入り**
- 筋肉痛があるからタンパク質を足す、ではなく、**1日の合計量を満たすこと** を優先する

## サプリメント

| サプリ | 考え方 |
| --- | --- |
| プロテイン | 食事で足りない分を補う「食べ物」として使う |
| BCAA | 1日のタンパク質が足りていればいらない。持っている分は、長いトレーニングのときに「カロリーゼロのスポーツドリンク」代わりに使う |
| マグネシウム | 暑くて汗を大量にかく環境では不足しやすい。寝る前にグリシン酸 or クエン酸マグネシウムを200〜300mgから。酸化マグネシウムは吸収されにくいので避ける |

## やりがちな失敗

| 失敗 | なぜダメか | 代わりにやること |
| --- | --- | --- |
| 1日の体重で一喜一憂する | 体重は水分で1〜2kg平気でブレる | 7日平均で見る |
| ご飯を目分量で盛る | いつの間にか食べすぎる。痩せなかった一番の原因 | 炊いた状態で量る |
| マシンの消費カロリーを足す | 多めに出るうえ、二重に数えることになる | 計算式だけを使う |
| 一気に大きく減らす | 筋肉が削られ、睡眠が崩れて続かない | 不足は1日 −400 前後、1,500kcal は下回らない |
