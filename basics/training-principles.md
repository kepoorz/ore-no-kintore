# 02. 筋トレの考え方

> 最適化の中心は「種目数を増やすこと」ではない。
> **同じフォーム・同じ ROM・同じ RIR 基準で、3か月・6か月単位で重量か回数を伸ばし続けること。**

## 採用している原則

| 項目 | 方針 |
| --- | --- |
| 分割 | 分割法そのものに優劣はない。総ボリュームを揃えれば分割と全身の差はほぼなくなる。**使える日数でボリュームを分散する手段** として選ぶ [[Ramos-Campo 2024]](references.md#ramos-campo-2024) |
| 頻度 | 原則として各筋群を 7日に約2回 |
| ボリューム | 大筋群は **週10〜15セット前後から開始**。伸びなくなった部位だけ後から増やす [[ACSM 2026]](references.md#acsm-2026) [[Pelland 2026]](references.md#pelland-2026) |
| RIR | 重いコンパウンド 2、補助種目 1〜2、アイソレーション 1 |
| Failure | 常用しない。肥大は failure に近いほど有利な傾向があるが、筋力は余力を残しても同程度に伸び、最適な RIR は未確定。安全なマシン/ケーブルの最終セットだけ任意で RIR0 [[Robinson 2024]](references.md#robinson-2024) [[ACSM 2026]](references.md#acsm-2026) |
| 休憩 | 大型コンパウンド 2.5〜4分、その他 1〜2分。60秒超で肥大に小さな利点、90秒超で差は検出されない。長めにとるのは次のセットの質を保つため [[Singer 2024]](references.md#singer-2024) |
| テンポ | 下ろしを 1〜3秒コントロール。「必ず3秒」は採用しない [[ACSM 2026]](references.md#acsm-2026) |
| 進め方 | ダブルプログレッション + RIR |
| デロード | 固定スケジュールではなく、疲労・成績低下に応じて実施（予定どおりの完全休止に利点が乏しいという研究からの推論） [[Coleman 2024]](references.md#coleman-2024) |

### ボリュームの逓減効果

週あたりセット数を増やすほど筋肥大は概ね増えるが、**1セットあたりのリターンは逓減する** [[Pelland 2026]](references.md#pelland-2026)。
「20セットは10セットの2倍効く」とは考えない。15セット前後で重量・回数が伸びるかを先に見る。経験者でもボリュームを増やした群が維持群を上回らなかった研究がある [[Barsuhn 2025]](references.md#barsuhn-2025)。

## ダブルプログレッション

例：インクライン DB プレス `3 × 8〜12 @RIR1〜2`

| セッション | 回数 | 判定 |
| --- | --- | --- |
| A | 10 / 9 / 8 | 同重量継続 |
| B | 11 / 10 / 9 | 進歩 |
| C | 12 / 11 / 10 | 同重量 |
| D | 12 / 12 / 12（RIR1〜2） | **次回増量** |
| E | 増量後 9 / 8 / 8 | 正常 |

- 全セットでレンジ上限に到達し、RIR とフォームが守れていたら **使える最小の刻み** で増量
- 目安：上半身 2〜5%、下半身 2.5〜5%
- RIR は誤差がある。「フォームを崩さないと上がらない一歩手前」を目安にし、1 か 2 かを神経質に当てない

## テンポ表記

`2–0–X–0` = 下ろす2秒 → 底で停止なし → できるだけ力強く挙上 → 上で停止なし

| 種目タイプ | テンポ |
| --- | --- |
| プレス・ロー・プル | 2–0–X–0 |
| スクワット | 2〜3–0–X–0 |
| RDL | 3–1–X–0 |
| カール・三頭・レイズ | 2–1–1–0 |
| フライ / ペックデック | 2–1–1–1 |
| カーフ | 2–2–1–1（ボトムで2秒止めて伸張位を安定させる） |

`X` は勢い任せではなく、「フォームを保ったまま速く動かす意図」。

## ウォームアップ

ウォームアップセットは本セット数に含めない。

1. 3〜5分の楽なウォーキング
2. その日使う関節を痛みのない範囲で動かす
3. 第一種目をランプアップ：`かなり軽い × 10 → 約50% × 6〜8 → 約70% × 4〜5 → 約80〜85% × 1〜3` [[Ribeiro 2020]](references.md#ribeiro-2020)
4. 第二の重いコンパウンドには 1〜2セットの導入セット

「温める」と「疲れさせる」を区別する。ウォームアップで RIR を削らない。

## 導入期（新しいプログラムを始めるとき）

| 期間 | セット量 | RIR |
| --- | --- | --- |
| 第1週 | 3〜4セット指定の種目を各1セット削る | 3程度 |
| 第2週 | 標準の 80〜90% | 2〜3 |
| 第3週以降 | 標準量 | コンパウンド2、補助1〜2 |

**筋肉痛の強さを成長の指標にしない。** 判断基準は、同じフォーム・ROM で重量や回数が伸びているか。

## セット数を増やす条件

同じ筋群について次をすべて満たすときだけ、A日・B日に各 +1セット程度を検討する。

- [ ] 2〜3週間、重量も回数も伸びていない
- [ ] 睡眠・食事・フォームに大きな問題がない
- [ ] 関節痛がない
- [ ] セッション間で十分回復している

**順調に伸びている筋群にはセットを足さない。** [[Barsuhn 2025]](references.md#barsuhn-2025)

## デロード

### トリガー（複数が同時に続いたら）

| 疲労サイン | 重み |
| --- | --- |
| 同じ種目で2回以上連続して 5〜10% のパフォーマンス低下 | 強 |
| 同じ重量・回数なのに RIR が急に悪化 | 中 |
| 筋肉痛がいつもより長引く | 補助 |
| 肘・肩・膝・腰の違和感が増える | セット削減を優先 |
| 睡眠・食欲・意欲が同時に落ちる | 全身疲労を疑う |

### 実施内容

- 5〜7日、セット数を約 40〜60% 削減
- RIR 3〜4、必要なら重量を 5〜10% 下げる
- 完全休養は体調不良・痛みなど別の理由があるときだけ

## 種目選択の考え方

### ハムストリングスは2つの動作を必ず残す

| 機能 | 種目 | 週セット |
| --- | --- | --- |
| 股関節伸展 | RDL | 4 |
| 膝屈曲 | ケーブルレッグカール / Nordic 等 | 4 |

RDL だけではハムストリングスは完結しない。動作によって部位別の適応が異なるため、両方を入れる [[Morin 2025]](references.md#morin-2025) [[Maeo 2021]](references.md#maeo-2021)。
スクワットもハムストリングスの種目としては数えすぎない [[Kubo 2019]](references.md#kubo-2019)。

### 角度・グリップは「バイアス」であって絶対値ではない

| 変更 | 使い方 |
| --- | --- |
| インクライン角度 | 30°固定ではなく 25〜40°で肩が快適な角度を記録し、毎回同じ設定で進歩を測る（30°の根拠は筋電図研究で、肥大は測っていない） [[Rodríguez-Ridao 2020]](references.md#rodriguez-ridao-2020) |
| ラットプルダウンの手幅 | 極端なワイドは不要。肩幅〜1.5倍の快適な ROM を優先 [[Andersen 2014]](references.md#andersen-2014) |
| ローの肘の軌道 | 肘を腰へ → 広背筋寄り / 肘を開いて胸へ → 上背部・リアデルト寄り |
| 三頭筋 | 腕を頭上にしたオーバーヘッドエクステンションを優先（長頭を伸ばした位置で鍛える） [[Maeo 2023]](references.md#maeo-2023) |
| カールの前腕 | 回外 = 二頭寄り / ニュートラル = 上腕筋・腕橈骨筋も / 回内 = 前腕寄り（筋電図研究） [[Coratella 2023]](references.md#coratella-2023) |
| ラテラルレイズ | ケーブルとダンベルで効果は同程度。A/B で使い分けるのは関節ストレスの分散のため [[Larsen 2025b]](references.md#larsen-2025b) |
| カーフ | スタンディングを主力にする（腓腹筋の肥大がシーテッドより大きい） [[Kinoshita 2023]](references.md#kinoshita-2023) |

いずれも「1つの筋だけに切り替わる」わけではなく、負荷配分と関節の快適さを変えるもの。

### 安全

- バーベルがあっても、ラック・セーフティがなければ高重量のフリースクワット / ベンチは行わない → スミスマシンを基本にする
- スクワットの深さを目的化しない。骨盤・腰椎を制御できる範囲で十分に深く（深いほど臀筋・内転筋の発達が大きい） [[Kubo 2019]](references.md#kubo-2019)
- RDL は床に届かせることを目標にしない。背骨中立でハムの強い伸張を感じる位置で折り返す
- Nordic をスミスバーの下でやる場合、バーが確実に固定されていることを確認できなければやらない

## 意図的に採用していないルール

| ルール | 不採用の理由 |
| --- | --- |
| 全種目3秒エキセントリック必須 | 特定の TUT に一貫した優位性がない [[ACSM 2026]](references.md#acsm-2026) |
| 毎セット failure | 必須ではなく、疲労が増える |
| 30°インクライン固定 | 急性の EMG 結果を長期の肥大へ外挿しすぎ [[Rodríguez-Ridao 2020]](references.md#rodriguez-ridao-2020) |
| ワイドプルダウン = 広背筋の幅 | グリップ幅の明確な優位性が乏しい [[Andersen 2014]](references.md#andersen-2014) |
| RDL だけでハム完結 | 膝屈曲機能を別途鍛える必要がある [[Morin 2025]](references.md#morin-2025) |
| レッグエクステンションでつま先を強くねじる | 根拠が弱い。中立が基本 |
| 毎回30〜40分の高傾斜歩行 | 脚の疲労と目的に応じて量を変える |
| 3時間使い切る | ボリュームの追加利益は逓減する |
| A日=筋力、B日=代謝ストレスと完全分離 | 特殊なピリオダイゼーション自体の優位性は明確でない [[ACSM 2026]](references.md#acsm-2026) |

参考文献は [references.md](references.md)。
