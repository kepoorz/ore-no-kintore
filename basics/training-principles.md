# 筋トレの原則

> **大事なのは、種目をたくさん増やすことではない。**
> **同じフォーム・同じ動かす範囲・同じきつさの基準で、3か月・6か月かけて重さか回数を伸ばし続けること。**

このページでは、実際にトレーニングするときの「やり方のルール」をまとめている。
このページで分かることは次のとおり。

- 1週間に何回・何セットやればいいか、どこまで追い込むか
- 重さを上げるタイミング（ダブルプログレッション）
- ウォームアップ、新しいメニューの始め方、休む週（デロード）の入れ方
- 種目の選び方と、このwikiがあえて採用していないルール

出てくる用語で分からないものは [用語集](../glossary.md) を見ればいい。特によく出てくるのは次の4つである。

| 用語 | 意味 |
| --- | --- |
| RIR（アールアイアール） | 「あと何回できたか」。RIR2 = あと2回できる余力を残してセットを終える |
| ROM（アールオーエム） | 可動域。関節を動かす範囲のこと |
| コンパウンド種目 | 複数の関節を使う種目（スクワット、ベンチプレス、ローなど） |
| アイソレーション種目 | 1つの関節だけを使う種目（カール、レイズなど） |

## このwikiの基本ルール

| 項目 | このwikiのやり方 |
| --- | --- |
| 分割 | 「上半身の日・下半身の日」のように分ける（分割法）か、毎回全身をやるかに優劣はない。1週間の合計セット数をそろえれば、差はほぼなくなる。**使える日数にセットを振り分けるための手段** として選べばいい [[Ramos-Campo 2024]](references.md#ramos-campo-2024) |
| 頻度 | 基本は、それぞれの筋肉を **1週間に約2回** |
| ボリューム（量） | 大きな筋肉は **1週間に10〜15セット前後から始める**。伸びなくなった部位だけ、後から増やす [[ACSM 2026]](references.md#acsm-2026) [[Pelland 2026]](references.md#pelland-2026) |
| RIR（余力） | 重いコンパウンド種目は 2、補助の種目は 1〜2、アイソレーション種目は 1 |
| 限界まで追い込む（failure） | いつもはやらない。筋肉を大きくするには限界に近いほど少し有利な傾向があるが、筋力は余力を残しても同じくらい伸びる。どこまで追い込むのが一番いいかは、まだはっきりしていない。安全なマシンやケーブル種目の最後のセットだけ、やりたければ RIR0（限界まで）でもいい [[Robinson 2024]](references.md#robinson-2024) [[ACSM 2026]](references.md#acsm-2026) |
| セット間の休憩 | 大きなコンパウンド種目は 2.5〜4分、それ以外は 1〜2分。60秒より長いと筋肥大に少しだけ有利で、90秒を超えると差は見られない。長めに休むのは、次のセットでもちゃんと回数をこなすため [[Singer 2024]](references.md#singer-2024) |
| 動かす速さ（テンポ） | 下ろすときは 1〜3秒かけてコントロールする。「必ず3秒」にはこだわらない [[ACSM 2026]](references.md#acsm-2026) |
| 重さの上げ方 | ダブルプログレッション + RIR（→ [下で説明](#ダブルプログレッション)） |
| デロード（軽めの週） | 日程を決めて入れるのではなく、疲れや成績の落ち込みが出たら入れる（予定どおりに完全に休んでも利点が少ない、という研究から考えたもの） [[Coleman 2024]](references.md#coleman-2024) |

### セットを増やすほど、1セットあたりの効果は小さくなる

1週間のセット数を増やすほど、筋肉はだいたい大きくなる。ただし **1セット増やしたときの上乗せは、だんだん小さくなっていく** [[Pelland 2026]](references.md#pelland-2026)。

| よくある考え | このwikiの考え |
| --- | --- |
| 20セットやれば10セットの2倍効く | 2倍にはならない。まず15セット前後で重さ・回数が伸びるかを見る |
| 経験者はとにかく量を増やすべき | 経験者でも、セットを増やしたグループが増やさなかったグループを上回らなかった研究がある [[Barsuhn 2025]](references.md#barsuhn-2025) |

## ダブルプログレッション

**ダブルプログレッション** とは、「まず回数を増やし、回数の上限まで届いたら重さを上げる」という進め方である。回数と重さの2段階で伸ばすので、この名前がついている。

例：インクラインダンベルプレス `3 × 8〜12 @RIR1〜2`
（3セット、1セット8〜12回、あと1〜2回できる余力で止める、という意味）

| 回 | 各セットの回数 | どうするか |
| --- | --- | --- |
| A | 10 / 9 / 8 | 同じ重さで続ける |
| B | 11 / 10 / 9 | 伸びている |
| C | 12 / 11 / 10 | 同じ重さで続ける |
| D | 12 / 12 / 12（余力1〜2回） | **次回、重さを上げる** |
| E | 重さを上げて 9 / 8 / 8 | 回数が落ちるのは当然。問題なし |

- すべてのセットで回数の上限に届き、余力とフォームも守れていたら、**用意できる一番小さい刻み** で重さを上げる
- 上げ幅の目安：上半身 2〜5%、下半身 2.5〜5%
- RIR は自分の感覚なので、ズレがあって当たり前。「フォームを崩さないと挙がらない、その一歩手前」を目安にして、1 なのか 2 なのかを神経質に気にしない

## テンポ表記

テンポは4つの数字で書く。`2–0–X–0` なら次の意味である。

| 位置 | 数字 | 意味 |
| --- | --- | --- |
| 1つ目 | 2 | 2秒かけて下ろす |
| 2つ目 | 0 | 一番下で止まらない |
| 3つ目 | X | できるだけ力強く挙げる |
| 4つ目 | 0 | 一番上で止まらない |

| 種目のタイプ | テンポ |
| --- | --- |
| プレス・ロー・プル系 | 2–0–X–0 |
| スクワット | 2〜3–0–X–0 |
| RDL（ルーマニアンデッドリフト） | 3–1–X–0 |
| カール・三頭（上腕三頭筋）・レイズ | 2–1–1–0 |
| フライ / ペックデック | 2–1–1–1 |
| カーフ（ふくらはぎ） | 2–2–1–1（一番下で2秒止めて、伸びた位置を安定させる） |

> `X` は「勢いまかせに振り回す」ことではない。**フォームを保ったまま、速く動かそうとする** という意味である。

## ウォームアップ

ウォームアップのセットは、その日のセット数に数えない。

1. 3〜5分、楽なペースで歩く
2. その日使う関節を、痛くない範囲で動かす
3. 最初の種目は、軽い重さから少しずつ重くしていく：`かなり軽い × 10回 → 本番の約50% × 6〜8回 → 約70% × 4〜5回 → 約80〜85% × 1〜3回` [[Ribeiro 2020]](references.md#ribeiro-2020)
4. 2つ目の重いコンパウンド種目は、慣らしのセットを1〜2セットだけやる

> **「体を温める」と「体を疲れさせる」は別物である。**
> ウォームアップで疲れてしまい、本番セットの余力が減るようでは意味がない。

## 導入期（新しいプログラムを始めるとき）

新しいメニューを始めるときは、いきなり全部の量をやらない。最初の2週間で体を慣らす。

| 期間 | セット数 | RIR（余力） |
| --- | --- | --- |
| 1週目 | 3〜4セットと書かれた種目は、それぞれ1セット減らす | 3くらい |
| 2週目 | 通常の 80〜90% | 2〜3 |
| 3週目から | 通常どおり | コンパウンド種目2、補助の種目1〜2 |

**筋肉痛の強さで「効いたかどうか」を判断しない。** 見るべきなのは、同じフォーム・同じ可動域で、重さや回数が伸びているかどうかである。

---

## セット数を増やしてもいい条件

同じ筋肉について、次の **すべて** に当てはまるときだけ、A日・B日にそれぞれ1セットずつ足すことを考える。

- [ ] 2〜3週間、重さも回数も伸びていない
- [ ] 睡眠・食事・フォームに大きな問題がない
- [ ] 関節が痛くない
- [ ] 次のトレーニングまでに、ちゃんと回復できている

**順調に伸びている筋肉には、セットを足さない。** [[Barsuhn 2025]](references.md#barsuhn-2025)

## デロード

**デロード** とは、たまった疲れを抜くために、一時的にセット数を減らして軽めに過ごす期間のことである。

### 入れるタイミング（次のサインがいくつも同時に続いたら）

| 疲れのサイン | 重要度 |
| --- | --- |
| 同じ種目で、2回以上続けて成績が 5〜10% 落ちる | 高い |
| 同じ重さ・回数なのに、急にきつく感じる（余力が減る） | 中くらい |
| 筋肉痛がいつもより長引く | 参考程度 |
| 肘・肩・膝・腰の違和感が増えてきた | まずセット数を減らす |
| 睡眠・食欲・やる気が同時に落ちる | 全身の疲れを疑う |

### やること

- 5〜7日間、セット数を 40〜60% くらい減らす
- 余力は RIR 3〜4 にする。必要なら重さも 5〜10% 下げる
- 完全に休むのは、体調不良や痛みなど、別の理由があるときだけ

## 種目の選び方

### ハムストリングス（太ももの裏）は、2種類の動きを必ず入れる

ハムストリングスには「股関節を伸ばす（上体を起こす）」働きと「膝を曲げる」働きの2つがある。

| 働き | 種目 | 1週間のセット数 |
| --- | --- | --- |
| 股関節を伸ばす | RDL（ルーマニアンデッドリフト） | 4 |
| 膝を曲げる | ケーブルレッグカール / Nordic ハムストリングカール など | 4 |

**RDL だけでは、ハムストリングスは鍛えきれない。** 動きによって筋肉のどの部分が育つかが違うので、両方を入れる [[Morin 2025]](references.md#morin-2025) [[Maeo 2021]](references.md#maeo-2021)。
また、スクワットをハムストリングスの種目として数えすぎないこと [[Kubo 2019]](references.md#kubo-2019)。

### 角度や握り方は「寄せる」ためのもので、決定的な違いではない

| 変えるところ | 使い方 |
| --- | --- |
| インクラインベンチの角度 | 30°に固定せず、25〜40°の中で肩が楽な角度を探して記録し、毎回同じ角度で伸びを測る（「30°がいい」の根拠は筋電図＝EMG（筋肉の電気信号）の研究で、筋肉が大きくなるかどうかは測っていない） [[Rodríguez-Ridao 2020]](references.md#rodriguez-ridao-2020) |
| ラットプルダウンの手幅 | 極端に広くする必要はない。肩幅〜1.5倍くらいで、無理なく大きく動かせる幅を選ぶ [[Andersen 2014]](references.md#andersen-2014) |
| ロー（引く種目）の肘の動き | 肘を腰の方へ引く → 広背筋寄り / 肘を開いて胸の方へ引く → 背中の上部・肩の後ろ（リアデルト）寄り |
| 上腕三頭筋 | 腕を頭の上に上げた姿勢でやるオーバーヘッドエクステンションを優先する（三頭筋の長頭という部分を、伸びた位置で鍛えられる） [[Maeo 2023]](references.md#maeo-2023) |
| カールの手の向き | 手のひらが上 = 二頭筋寄り / 親指が上 = 上腕筋・腕橈骨筋も使う / 手のひらが下 = 前腕寄り（筋電図の研究） [[Coratella 2023]](references.md#coratella-2023) |
| サイドレイズ（ラテラルレイズ） | ケーブルでもダンベルでも効果は同じくらい。A日とB日で使い分けるのは、関節への負担を散らすため [[Larsen 2025b]](references.md#larsen-2025b) |
| カーフ | 立ってやるスタンディングカーフレイズをメインにする（座ってやるより、ふくらはぎの腓腹筋が大きくなった） [[Kinoshita 2023]](references.md#kinoshita-2023) |

> どれも「ひとつの筋肉だけに効くように切り替わる」わけではない。
> **負荷のかかり方を少し寄せたり、関節を楽にしたりするための調整** である。

### 安全のために

- バーベルがあっても、ラックやセーフティバー（落としたときに受け止める棒）がなければ、重いスクワット・ベンチプレスをバーベルでやらない → スミスマシンを基本にする
- スクワットは深くしゃがむこと自体を目標にしない。骨盤と腰をコントロールできる範囲で、できるだけ深く（深いほうがお尻と内ももは発達しやすい） [[Kubo 2019]](references.md#kubo-2019)
- RDL はバーを床につけることを目標にしない。背中をまっすぐ保ったまま、太ももの裏が強く伸びたところで折り返す
- Nordic ハムストリングカールをスミスマシンのバーに足を引っかけてやる場合、バーがしっかり固定されていると確認できなければやらない

## よくある考え vs このwikiの考え（あえて採用していないルール）

| よく聞くルール | このwikiが採用しない理由 |
| --- | --- |
| 全種目、3秒かけて下ろさないといけない | 筋肉に負荷がかかっている時間（TUT）を長くしても、はっきりした効果の差がない [[ACSM 2026]](references.md#acsm-2026) |
| 毎セット限界まで追い込む | 必須ではないし、疲れがたまるだけ |
| インクラインは30°に固定 | 一時的な筋電図の結果を、長期間の筋肥大に当てはめすぎている [[Rodríguez-Ridao 2020]](references.md#rodriguez-ridao-2020) |
| 広い手幅のラットプルダウンで背中が広くなる | 手幅による、はっきりした差は見つかっていない [[Andersen 2014]](references.md#andersen-2014) |
| ハムストリングスは RDL だけで十分 | 膝を曲げる動きは別に鍛える必要がある [[Morin 2025]](references.md#morin-2025) |
| レッグエクステンションでつま先を強くひねる | 根拠が弱い。まっすぐが基本 |
| 毎回30〜40分、傾斜をきつくしたウォーキング | 脚の疲れ具合と目的に合わせて量を変える |
| ジムにいられる3時間をフルに使う | 量を増やしても、上乗せの効果はだんだん小さくなる |
| A日は筋力、B日はパンプ（代謝ストレス）とはっきり分ける | 時期や日によって内容を細かく変える特殊な組み方（ピリオダイゼーション）に、はっきりした優位性は見つかっていない [[ACSM 2026]](references.md#acsm-2026) |

## やりがちな失敗

| 失敗 | なぜダメか | 代わりにやること |
| --- | --- | --- |
| 伸び悩んだらすぐセット数を増やす | 量を増やしても効果は2倍にならず、疲れだけ増える | [増やしていい条件](#セット数を増やしてもいい条件) をすべて満たすか確認する |
| 回数の上限に届く前に重さを上げる | フォームが崩れ、伸びているのか分からなくなる | 全セットで上限に届いてから、最小の刻みで上げる |
| 筋肉痛がないと効いていないと思う | 筋肉痛の強さと成長は比例しない | 重さ・回数が伸びているかで判断する |
| 毎回ベンチの角度や手幅を変える | 前回と比べられなくなる | 設定を記録して、毎回同じにする |
| ウォームアップで疲れきる | 本番セットの回数が落ちる | 少しずつ重くし、回数は少なめにする |

## まとめ

- **同じフォーム・同じ可動域で、重さか回数を少しずつ伸ばす**
- **大きな筋肉は1週間に10〜15セット、各筋肉を週2回から**
- **限界まではいつも追い込まない。余力1〜2回で止める**
- **回数の上限に届いたら、一番小さい刻みで重さを上げる**
- **疲れのサインが重なったら、デロードで軽めにする**

参考文献は [references.md](references.md)。
