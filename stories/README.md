# 体験談

参加者の「やってみた」の記録。成功談だけでなく、失敗談・挫折談も歓迎。
同じところで詰まっている誰かの助けになる。

## 書き方

1. [_template.md](_template.md) をコピーして `YYYY-MM-ハンドル名-タイトル.md` で保存
2. PR を送る

## 注意

- 本名・顔写真・住所など、個人が特定できる情報は書かない
- 医療的な主張（「○○が治った」など）は書かない
