# ブルガリアンスプリットスクワット（Bulgarian Split Squat）

| 項目 | 内容 |
| --- | --- |
| 部位 | 脚 |
| 主働筋 | 大腿四頭筋、大臀筋 |
| 補助筋 | 内転筋群、中臀筋（バランス）、ハムストリングス |
| 器具 | ダンベル + ベンチ / 自重 |
| 難易度 | ★★★ |
| 動作パターン | スクワット |
| 推奨レップ | 8〜12 / 脚（自重は 8〜20 / 脚） |
| 推奨RIR | 1〜2（DB のみ・自重版の第一種目は 2） |
| テンポ | 2–0–X–0 |
| 登場プログラム | [6日](../programs/6-day.md)（Legs A） / [4日](../programs/4-day.md)（Lower A） / [5日](../programs/5-day.md)（Legs） / [3日](../programs/3-day.md)（Full B） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Legs A / B） / [自重のみ](../programs/variants/bodyweight-only.md)（Legs A / B） |

## なぜやるのか
片脚なので軽い外部負荷でも脚に高い負荷がかかり、ダンベルのみ・自重環境でもスクワットの主力になる。
左右差の確認と、内転筋・臀筋への深い刺激も得られる。

## やり方
1. ベンチの前に立ち、片足の甲をベンチに乗せる
2. 前足は、しゃがんだとき膝と足首が無理なく曲がる位置に置く
3. 上体をやや前傾させ、2秒かけて後ろ膝を床に近づける
4. 前脚の足裏全体で床を押して立ち上がる
5. 片側のレップを終えてから脚を入れ替える

## よくあるミス
- 前足がベンチに近すぎ / 遠すぎてバランスを崩す
- 前膝が内側に入る
- 後ろ脚で蹴って立ち上がる
- 毎回前足の位置が違い、記録が比較できない

## 初心者向けのコツ
- 最初は自重・RIR3〜4 で、足の位置（ベンチから何足分か）を決めて記録する
- ふらつく場合は片手で柱などを持ってよい
- 膝・股関節に痛みが出たら中止し、前足の位置や深さを見直す

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ジム | [スミスマシン・スクワット](smith-squat.md) |
| バランスが不安 | DB リバースランジ / スミスでのスプリットスクワット |
| 膝に違和感 | 前足を遠めに置いて臀筋寄りにする / ROM を浅くする |

## 豆知識
- 上体を前傾させると臀筋寄り、立てると四頭寄りになりやすい。どちらも両方働く。
- DB の重量が足りなくなったら、スクワットのセットを増やすよりこの種目を重くする（ダンベルのみ版の方針）。
