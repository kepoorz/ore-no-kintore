# ストレートアーム・プルダウン（Straight-Arm Pulldown）

| 項目 | 内容 |
| --- | --- |
| 部位 | 背中 |
| 主働筋 | 広背筋 |
| 補助筋 | 大円筋、上腕三頭筋長頭、後部三角筋 |
| 器具 | クロスオーバーケーブル（ストレートバー / ロープ） |
| 難易度 | ★★☆ |
| 動作パターン | 垂直プル（補助。肩関節伸展のアイソレーション） |
| 推奨レップ | 10〜15 |
| 推奨RIR | 1 |
| テンポ | 2–1–1–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Pull B） |

## なぜやるのか
肘を曲げないため、二頭や握力の関与を減らして広背筋の肩関節伸展だけを狙える。
ロー・プルダウンで腕が先に疲れる人の補助として役立つ。

## やり方
1. プーリーを頭より高くセットし、肩幅でバーを握る
2. 一歩下がり、股関節から軽く前傾して背骨を中立に保つ
3. 肘を軽く曲げたまま固定し、腕を弧を描いて太腿の前まで下ろす
4. 下で1秒止める
5. 2秒かけて腕が頭の前に戻るまでコントロールし、1秒止める

## よくあるミス
- 肘を曲げ伸ばしして、プッシュダウンになる
- 上体を大きく倒して体重で下ろす
- 戻しで肩がすくみ、張力が抜ける

## 初心者向けのコツ
- 軽い重量・RIR3〜4 で、肘角度を固定する感覚を先に覚える
- 鏡で横から見て、上体の角度が変わっていないか確認する
- 肩に痛みが出たら中止し、ROM を小さくする
