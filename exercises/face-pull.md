# フェイスプル（Face Pull）

| 項目 | 内容 |
| --- | --- |
| 部位 | 肩 |
| 主働筋 | 後部三角筋 |
| 補助筋 | 僧帽筋中部・下部、菱形筋、棘下筋・小円筋 |
| 器具 | クロスオーバーケーブル（ロープ） |
| 難易度 | ★★☆ |
| 動作パターン | 水平プル寄りの後肩アイソレーション（置き換え表の対象外） |
| 推奨レップ | 12〜20 |
| 推奨RIR | 1 |
| テンポ | 2–1–1–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Pull B） |

## なぜやるのか
後部三角筋と上背部を、肩の外旋を伴う形で鍛える。
Pull A のリバースペックデックとは別の角度から肩の後ろ側を補い、関節ストレスも分散できる。

## やり方
1. プーリーを顔〜目の高さにセットし、ロープを親指が後ろを向く形で握る
2. 一歩下がり、体幹を固定して腕を伸ばす
3. ロープを顔の方へ引き、手を耳の横へ広げるように肘を開く
4. 引き切った位置で1秒止める
5. 2秒かけて腕が伸びるまで戻し、1秒止める

## よくあるミス
- 重すぎて上体を後ろに倒して引く
- 肘が下がり、普通のローになる
- 肩がすくんで首に効く

## 初心者向けのコツ
- 重量は軽くてよい。RIR3〜4 で「手を耳の横へ」の形を覚える
- 引く位置が首に近づきすぎないよう、顔の前で止めてもよい
- 肩に痛みが出たら中止し、プーリーの高さと ROM を見直す

## 豆知識
- 後部三角筋は肘を開くロー系からも刺激を受ける。直接種目は「足りない分を補う」位置づけ。
