# トライセプス・プッシュダウン（Triceps Pushdown）

| 項目 | 内容 |
| --- | --- |
| 部位 | 腕 |
| 主働筋 | 上腕三頭筋（外側頭・内側頭寄り） |
| 補助筋 | — |
| 器具 | クロスオーバーケーブル（ロープ / バー） |
| 難易度 | ★☆☆ |
| 動作パターン | 肘伸展アイソレーション（置き換え表の対象外） |
| 推奨レップ | 10〜15 |
| 推奨RIR | 1 |
| テンポ | 2–1–1–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Push B） / [4日](../programs/4-day.md)（Upper B） / [5日](../programs/5-day.md)（Push） |

## なぜやるのか
肘と肩への負担が小さく、三頭を安定して追い込める定番種目。
Push A のオーバーヘッド版と A/B で分け、角度と関節ストレスを分散する。

## やり方
1. プーリーを頭より高くセットし、ロープかバーを握る
2. 肘を体の横に固定し、上体をわずかに前傾させる
3. 肘の位置を変えずに、前腕だけで下へ伸ばし切る
4. 伸ばし切った位置で1秒止める
5. 2秒かけて前腕が床と平行より上に来るまで戻し、1秒止める

## よくあるミス
- 肘が前後に動き、肩や体重で押し下げる
- 重すぎて上体を大きくかぶせる
- 戻しが浅く、ROM が短い

## 初心者向けのコツ
- RIR3〜4 の重量で、肘を脇腹に貼りつけたまま動かす練習をする
- ロープは下で少し外へ開くと、伸ばし切りやすい
- 肘に痛みが出たら中止し、アタッチメントを変えて試す

## 豆知識
- 三頭の優先はオーバーヘッド系。プッシュダウンは補完と関節負担の分散のために残している。
