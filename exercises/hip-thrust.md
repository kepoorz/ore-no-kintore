# ヒップスラスト（Hip Thrust）

| 項目 | 内容 |
| --- | --- |
| 部位 | 脚 |
| 主働筋 | 大臀筋 |
| 補助筋 | ハムストリングス、内転筋群、大腿四頭筋 |
| 器具 | スミスマシン / バーベル / ダンベル + ベンチ |
| 難易度 | ★★☆ |
| 動作パターン | 股関節伸展（置き換え表の対象外。ヒップヒンジの補完） |
| 推奨レップ | 8〜12（DB のみ版は 8〜15） |
| 推奨RIR | 1〜2 |
| テンポ | 2–1–X–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Legs B） / [4日](../programs/4-day.md)（Lower B） / [5日](../programs/5-day.md)（Legs） / [3日](../programs/3-day.md)（Full C） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Legs B） / [自重のみ](../programs/variants/bodyweight-only.md)（Legs B：片脚） |

## なぜやるのか
股関節を伸ばし切った位置で大臀筋に強い負荷をかけられる、臀筋の専用種目。
腰への負担が RDL より小さく、Legs B の臀筋の主力にする。

## やり方
1. ベンチの側面に肩甲骨の下あたりをつけて座り、バー（パッド付き）を骨盤の上に乗せる
2. 足を腰幅に開き、トップで膝が約90°になる位置に置く
3. 顎を軽く引き、肋骨を締める
4. 踵で床を押し、股関節を伸ばし切るまで腰を持ち上げる
5. トップで1秒止め、2秒かけて下ろし、下で1秒止める

## よくあるミス
- トップで腰を反らして「伸ばした」つもりになる
- 足が近すぎ / 遠すぎで、四頭やハムに逃げる
- バーの位置がずれ、骨盤が痛む

## 初心者向けのコツ
- まず自重 → 軽いバー・RIR3〜4 で足の位置を決めて記録する
- 骨盤に当たって痛い場合はパッドやタオルを使う
- 腰に痛みが出たら中止し、トップで反りすぎていないか確認する

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ダンベルのみ | DB ヒップスラスト |
| 自重 | シングルレッグ・ヒップスラスト |
| 腰に違和感 | 自重・片脚版で ROM を小さくする |

## 豆知識
- 臀筋は [スミスマシン・スクワット](smith-squat.md) や [RDL](romanian-deadlift.md) からも刺激を受ける。ヒップスラストは「専用で足りない分を足す」位置づけ。
