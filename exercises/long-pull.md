# ロングプル / シーテッドロウ（Seated Cable Row）

| 項目 | 内容 |
| --- | --- |
| 部位 | 背中 |
| 主働筋 | 広背筋（ニュートラル・肘を腰へ） / 僧帽筋中部・菱形筋（ワイド・肘を開く） |
| 補助筋 | 後部三角筋、上腕二頭筋、上腕筋、脊柱起立筋（姿勢保持） |
| 器具 | ロングプル（シーテッドケーブルロウ） |
| 難易度 | ★☆☆ |
| 動作パターン | 水平プル |
| 推奨レップ | 8〜12 |
| 推奨RIR | 1〜2 |
| テンポ | 2–1–X–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Pull A：ニュートラル / Pull B：ワイド） / [4日](../programs/4-day.md)（Upper A / B） / [5日](../programs/5-day.md)（Upper / Pull） / [3日](../programs/3-day.md)（Full B / C） |

## なぜやるのか
水平方向に引く主力で、アタッチメントと肘の軌道で狙いを変えられる。
A日は肘を腰へ（広背筋寄り）、B日は肘を開く（上背部・リアデルト寄り）と使い分け、背中全体を週2回カバーする。

## やり方
1. 足をフットプレートに置き、膝を軽く曲げて座る
2. 背骨を中立に保ち、胸を軽く張る
3. 肩甲骨を寄せながら引き始める
4. A日：ニュートラルで肘を腰へ。B日：ワイドで肘を開いて胸へ
5. 引き切った位置で1秒止める
6. 2秒かけて肩甲骨が前に出るまで戻し、1秒止める

## よくあるミス
- 上体を大きく前後に振り、腰で引く
- 戻しで背中が丸まり、腰に負担がかかる
- 肩がすくみ、首に効いてしまう
- 肘の軌道が日によって違い、記録が比較できない

## 初心者向けのコツ
- 導入期は RIR3 程度の重量で、上体を固定したまま引けるか確認する
- 「手で引く」より「肘を後ろへ」の意識
- 腰に痛みが出たら中止し、重量を下げて上体の振りをなくす

## 豆知識
- 肘の軌道は「バイアス」であり、1つの筋だけに切り替わるわけではない。
- アタッチメントを変えたら、重量の比較はアタッチメントごとに行う。
