| 項目 | 内容 |
| --- | --- |
| 部位 | 肩 |
| 主働筋 | 中部三角筋 |
| 補助筋 | 僧帽筋上部、棘上筋 |
| 器具 | ケーブル（片手） / ダンベル |
| 難易度 | ★☆☆ |
| 動作パターン | 肩外転アイソレーション（置き換え表の対象外） |
| 推奨レップ | 12〜20 |
| 推奨RIR | 1 |
| テンポ | 2–1–1–0 |
| 登場プログラム | [6日](../programs/6-day.md)（Push A：片手ケーブル / Push B：DB） / [4日](../programs/4-day.md)（Upper A / B） / [5日](../programs/5-day.md)（Upper / Push） / [3日](../programs/3-day.md)（Full A / C） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Push A / B） |

## なぜやるのか
中部三角筋はプレス系だけでは十分な刺激が入りにくく、肩の横幅を作るには直接種目が必要。
軽い重量で高回数をこなせ、関節負担が小さいので週に多めのセットを入れやすい。

## やり方
1. ケーブルは足首の高さにセットし、体の横〜やや前に立つ（DB は両手に持つ）
2. 肘を軽く曲げ、体幹をわずかに前傾させる
3. 肘から先に、肩の高さ付近まで腕を横〜やや前に上げる
4. 上で1秒止める
5. 2秒かけて下ろし、下で張力を抜かずに次へ

## よくあるミス
- 重すぎて体を振り、僧帽筋で持ち上げる
- 手首が肘より上に来て、前腕だけ上がる
- 肩がすくむ
- 下で休んで張力を抜く

## 初心者向けのコツ
- 最初は驚くほど軽い重量でよい。RIR3〜4 で動作を覚える
- 「手を上げる」より「肘を遠くへ」の意識
- 肩に挟まるような痛みが出たら中止し、上げる高さを下げる・やや前方に上げる

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ダンベルのみ | DB ラテラルレイズ |
| 自重 | 有効な代替が乏しい。中部三角筋は自重版の弱点 |
| 肩に違和感 | ケーブル版で ROM を小さくする |

## 豆知識
- ケーブルとダンベルの肥大効果は同程度 [[Larsen 2025b]](../basics/references.md#larsen-2025b)。6日版で A/B に分けているのは、関節ストレスを分散するため。
