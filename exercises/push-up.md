# プッシュアップ（Push-up）

| 項目 | 内容 |
| --- | --- |
| 部位 | 胸 |
| 主働筋 | 大胸筋 |
| 補助筋 | 前部三角筋、上腕三頭筋、腹筋群（体幹の固定） |
| 器具 | 自重（床） |
| 難易度 | ★☆☆ |
| 動作パターン | 水平プッシュ |
| 推奨レップ | 8〜20 |
| 推奨RIR | 2（第一種目） / 1〜2（バリエーション） |
| テンポ | 2–0–X–0 |
| 登場プログラム | [自重のみ](../programs/variants/bodyweight-only.md)（Push A / B） |

## なぜやるのか
器具なしで胸・三頭を高水準で鍛えられる、出張・ホテル用の主力。
手幅・足の高さ・片側化でバリエーションを作れるので、自重でも漸進性過負荷を組める。

## やり方
1. 手を肩幅よりやや広く床につき、頭から踵までを一直線にする
2. 腹筋と臀筋を軽く締め、腰が落ちないようにする
3. 肘を体幹に対して斜めに曲げ、2秒かけて胸を床の近くまで下ろす
4. 底で止めずに、床を押し離すように力強く戻る
5. 肘を伸ばし切る手前〜伸ばし切るまで押す

## よくあるミス
- 腰が落ちる / 尻が上がり、体幹が一直線でない
- 肘を真横に張って肩の前に負担が集まる
- 首だけ前に出して ROM を稼いだつもりになる
- 30〜40回を延々と続け、負荷が上がらない

## 初心者向けのコツ
- 床で数回しかできないなら、台に手をついたインクライン（手が高い）版から始める
- 導入期は RIR3 程度で止め、体幹が一直線のままできる回数を記録する
- 手首や肩に痛みが出たら中止し、手の向き・手幅を変えて試す

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ジム | [スミス・ベンチプレス](smith-bench-press.md) / [チェストプレスマシン](chest-press-machine.md) |
| ダンベルのみ | DB フラットベンチプレス（[ダンベルのみ版](../programs/variants/dumbbell-only.md)） |
| 簡単すぎる | デクライン（足上げ）→ アーチャー → ボトム1〜2秒停止 |
| 上胸を狙う | デクラインプッシュアップ（足の高さ 20〜40cm から） |

## 豆知識
- 自重では「回数 → ROM → 不利なレバー → 片側化 → 足を高く → ボトム停止」の順で難易度を上げる。
- 8〜25回で RIR1〜2 になるバリエーションを選ぶと管理しやすい。
