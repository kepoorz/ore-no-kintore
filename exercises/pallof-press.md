# パロフプレス（Pallof Press）

| 項目 | 内容 |
| --- | --- |
| 部位 | コア |
| 主働筋 | 内腹斜筋・外腹斜筋、腹横筋 |
| 補助筋 | 腹直筋、臀筋群、肩周り（腕の保持） |
| 器具 | クロスオーバーケーブル / バンド |
| 難易度 | ★☆☆ |
| 動作パターン | コア・抗回旋（置き換え表の対象外） |
| 推奨レップ | 10〜15 / 側 |
| 推奨RIR | RPE8 |
| テンポ | 伸展位で1〜2秒保持 |
| 登場プログラム | [6日](../programs/6-day.md)（Push B） / [4日](../programs/4-day.md)（Lower B） / [5日](../programs/5-day.md)（Pull） / [3日](../programs/3-day.md)（Full C） |

## なぜやるのか
横から引っ張られる力に対し、体幹がねじれないよう耐える「抗回旋」を鍛える。
腰への負担が小さく、他の種目の疲労と干渉しにくい。

## やり方
1. プーリーを胸の高さにセットし、ケーブルに対して横向きに立つ
2. ハンドルを両手で胸の前に持ち、足を肩幅に開いて膝を軽く曲げる
3. 臀筋と腹筋を締め、骨盤と肩をまっすぐ前に向ける
4. 腕を胸の前へまっすぐ押し出し、1〜2秒保持する
5. 体幹が回らないまま胸の前に戻す。反対側も同じ回数行う

## よくあるミス
- 押し出したときに体がケーブル側へ回る
- 腰を反らせて耐える
- 重すぎて足の位置がずれる

## 初心者向けのコツ
- 軽い重量から。体が回らずに保持できる重量を選ぶ
- ケーブルから離れるほど負荷が上がる。立ち位置を記録する
- 腰に痛みが出たら中止する

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ケーブルがない | バンドで同じ動作 |
| ダンベルのみ | DB デッドバグ（[ダンベルのみ版](../programs/variants/dumbbell-only.md)） |
| 自重 | プランク・ショルダータップ（骨盤を回さない）（[自重のみ版](../programs/variants/bodyweight-only.md)） |

## 豆知識
- 重さより「ねじれない」ことが目的。RPE8 は保持を崩さずに続けられる限界が近い程度。
