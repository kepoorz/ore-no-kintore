# チェストサポート・ダンベルロー（Chest-Supported Dumbbell Row）

| 項目 | 内容 |
| --- | --- |
| 部位 | 背中 |
| 主働筋 | 僧帽筋中部、菱形筋、広背筋 |
| 補助筋 | 後部三角筋、上腕二頭筋、上腕筋 |
| 器具 | ダンベル、インクラインベンチ |
| 難易度 | ★☆☆ |
| 動作パターン | 水平プル |
| 推奨レップ | 8〜12（肘開きは 10〜15） |
| 推奨RIR | 1〜2 |
| テンポ | 2–1–X–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Pull A） / [5日](../programs/5-day.md)（Pull） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Pull A / B） |

## なぜやるのか
胸をベンチで支えるため、腰の負担と反動を抑えて背中だけに集中できる。
RDL など腰を使う種目と同じ週に入れても疲労が干渉しにくい。

## やり方
1. インクラインベンチを 30〜45° 程度にし、うつ伏せで胸をパッドにつける
2. 足で床を押して体を固定し、ダンベルを真下に垂らす
3. 肩甲骨を寄せながら肘を後ろへ引く（肘を腰へ / 肘を開く を目的で選ぶ）
4. 上で1秒止める
5. 2秒かけて肩甲骨が前に出るまで下ろし、1秒止める

## よくあるミス
- 胸がパッドから離れ、上体を起こして反動を使う
- 肩がすくんで首に効く
- 下ろしが浅く、肩甲骨が動いていない
- 首を反らしすぎる

## 初心者向けのコツ
- 導入期は RIR3〜4 の軽い重量で、胸をつけたまま引けるか確認する
- ベンチの角度を記録し、毎回同じにする
- 肩や腰に痛みが出たら中止し、角度や重量を見直す

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ケーブルがある | [ロングプル](long-pull.md) |
| ベンチがない | [ワンハンド DB ロー](one-arm-dumbbell-row.md) |
| 自重 | [インバーテッドロー](inverted-row.md) |
| 後部三角筋を狙う | [リバースペックデック](reverse-pec-deck.md) / [フェイスプル](face-pull.md) |

## 豆知識
- 肘を腰へ引くと広背筋寄り、肘を開いて胸へ引くと上背部・リアデルト寄りになる。どちらも背中全体が働く。
