# ハンマーカール（Hammer Curl）

| 項目 | 内容 |
| --- | --- |
| 部位 | 腕 |
| 主働筋 | 上腕筋、腕橈骨筋 |
| 補助筋 | 上腕二頭筋 |
| 器具 | ダンベル |
| 難易度 | ★☆☆ |
| 動作パターン | 肘屈曲アイソレーション（置き換え表の対象外） |
| 推奨レップ | 10〜15 |
| 推奨RIR | 1 |
| テンポ | 2–1–1–0 |
| 登場プログラム | [6日](../programs/6-day.md)（Pull A） / [4日](../programs/4-day.md)（Upper B） / [5日](../programs/5-day.md)（Pull） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Pull A） |

## なぜやるのか
ニュートラルグリップ（親指が上）で、上腕筋と腕橈骨筋にもしっかり負荷を入れる。
腕の太さと前腕の厚みを補い、手首に優しいので疲れた後半でも行いやすい。

## やり方
1. 立って両手にダンベルを持ち、手のひらを体側に向ける
2. 肘を体の横に固定する
3. 手の向きを変えずに、肩の方へ巻き上げる
4. 上で軽く止める
5. 2秒かけて肘が伸び切るまで下ろす

## よくあるミス
- 上体を振って反動で上げる
- 肘が前に出て、肩で持ち上げる
- 下ろしが速く、ROM が短い

## 初心者向けのコツ
- RIR3〜4 の重量から。左右交互でも同時でもよいが、毎回同じ方法にする
- 壁に背中をつけると反動が出にくい
- 肘や手首に痛みが出たら中止し、重量を下げる

## 豆知識
- 回外・ニュートラル・回内で負荷配分が変わる。6日版は Pull A で回外とニュートラル、Pull B でバーベルカールとリバースカールを使い分けている。
