| 項目 | 内容 |
| --- | --- |
| 部位 | 腕 |
| 主働筋 | 上腕二頭筋 |
| 補助筋 | 上腕筋、腕橈骨筋 |
| 器具 | ダンベル、インクラインベンチ |
| 難易度 | ★★☆ |
| 動作パターン | 肘屈曲アイソレーション（置き換え表の対象外） |
| 推奨レップ | 8〜12 |
| 推奨RIR | 1 |
| テンポ | 2–1–1–0 |
| 登場プログラム | [6日](../programs/6-day.md)（Pull A） / [4日](../programs/4-day.md)（Upper A） / [5日](../programs/5-day.md)（Upper） / [3日](../programs/3-day.md)（Full B） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Pull A） |

## なぜやるのか
上体を寝かせて腕を体より後ろに垂らすことで、肩関節をまたぐ二頭を伸ばした位置から鍛えられる。
回外（手のひらを上）で握り、二頭にバイアスをかける。

## やり方
1. ベンチを 45〜60° 程度に起こし、背中をつけて座る
2. ダンベルを持った腕を真下に垂らし、手のひらを前（回外）に向ける
3. 肘の位置を変えずに、手のひらを上に向けたまま巻き上げる
4. 上で1秒止める
5. 2秒かけて肘が伸び切るまで下ろす

## よくあるミス
- 肘が前に出て、肩で持ち上げる
- 背中がベンチから離れ、上体を起こして反動を使う
- 下ろしが浅く、ストレッチ位を使えていない

## 初心者向けのコツ
- 通常のカールより扱える重量は軽くなる。RIR3〜4 から始める
- ベンチ角度を記録し、毎回同じにする
- 肩の前や肘に痛みが出たら中止し、ベンチを起こして角度を緩める

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ベンチがない | DB カール / バーベルカール |
| 上腕筋も狙う | [ハンマーカール](hammer-curl.md) |
| 自重 | セルフレジスタンス・カール（[自重のみ版](../programs/variants/bodyweight-only.md)） |

## 豆知識
- 前腕の向きはバイアスを変える：回外 = 二頭寄り、ニュートラル = 上腕筋・腕橈骨筋も、回内 = 前腕寄り [[Coratella 2023]](../basics/references.md#coratella-2023)。どれも1つの筋だけに切り替わるわけではない。
