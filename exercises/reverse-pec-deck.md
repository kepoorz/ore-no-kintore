| 項目 | 内容 |
| --- | --- |
| 部位 | 肩 |
| 主働筋 | 後部三角筋 |
| 補助筋 | 僧帽筋中部、菱形筋、棘下筋 |
| 器具 | ペックデックマシン（リア側） |
| 難易度 | ★☆☆ |
| 動作パターン | 水平外転アイソレーション（置き換え表の対象外） |
| 推奨レップ | 12〜20 |

| 登場プログラム | [6日](../programs/6-day.md)（Pull A） / [4日](../programs/4-day.md)（Upper B） / [5日](../programs/5-day.md)（Pull） / [3日](../programs/3-day.md)（Full C） |

## なぜやるのか
後部三角筋はロー系でも使われるが、直接狙う種目があると肩の後ろ側を確実に鍛えられる。
軌道が固定されているので、軽い重量でも効かせやすい。

## やり方
1. シート高を、グリップが肩の高さに来るよう調整する
2. パッドに胸をつけ、肘を軽く曲げてグリップを握る
3. 肘の角度を固定したまま、腕を横に大きく開く
4. 開いた位置で1秒止める
5. 2秒かけて戻し、張力が抜ける手前で1秒止める

## よくあるミス
- 肩甲骨を強く寄せすぎて、背中の種目になる
- 肩がすくむ
- 重すぎて反動で開く

## 初心者向けのコツ
- 軽い重量・RIR3〜4 で、「肘を遠くへ開く」感覚を覚える
- 肩甲骨はやや開いたまま、腕だけを動かす意識でもよい
- 肩に痛みが出たら中止し、ROM を小さくする

## 豆知識
- 同じマシンを逆向きに使うと [ペックデック](pec-deck.md) になる機種が多い。
- 肘を開くロー（Pull B のロングプル・ワイド）でも後部三角筋は使われる。
