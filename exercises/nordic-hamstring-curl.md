# Nordic ハムストリングカール（Nordic Hamstring Curl）

| 項目 | 内容 |
| --- | --- |
| 部位 | 脚 |
| 主働筋 | ハムストリングス（膝屈曲・エキセントリック） |
| 補助筋 | 腓腹筋、大臀筋・腹筋群（体幹を一直線に保つ） |
| 器具 | 自重（足首を固定できるもの） |
| 難易度 | ★★★ |
| 動作パターン | 膝屈曲 |
| 推奨レップ | 補助付き 8〜15 / エキセントリックのみ 4〜8 × 3 程度 |
| 推奨RIR | 1〜2 |
| テンポ | 3–0–X–0 目安（下ろしはできる範囲でコントロール、戻りは手で補助してよい） |
| 登場プログラム | [6日](../programs/6-day.md)（Legs B：膝屈曲ハム種目の優先2・3） / [4日](../programs/4-day.md)（Lower B） / [5日](../programs/5-day.md)（Lower） |

## なぜやるのか
レッグカールマシンもケーブルカフもない環境で、膝屈曲のハム種目を確保する手段。
自重でも非常に強い負荷になり、少ない回数で十分な刺激が入る。

## やり方
1. 膝の下にマットを敷き、膝立ちになる
2. 足首を確実に固定する（パートナー、固定されたパッド等）
3. 膝から頭までを一直線に保ち、ゆっくり前へ倒れていく
4. 耐えられなくなったら手を床について受け止める
5. 手で床を押し、補助を使ってスタート位置に戻る

## よくあるミス
- 股関節を曲げて尻を後ろへ引き、ハムから逃げる
- 足首の固定が不確かなまま行う
- 導入期から回数をこなして強い筋肉痛を出す

## 初心者向けのコツ
- 最初はエキセントリックだけ・数回でよい。RIR3〜4 相当で止める
- バンドや手で床を押す補助を使い、徐々に補助を減らす
- スミスバーの下に足を入れて行う場合、バーが確実に固定されていると確認できなければやらない
- ハムに鋭い痛みが出たら直ちに中止する

## 代替種目
| 状況 | 代替 |
| --- | --- |
| 足首カフがある | [ケーブル・レッグカール](cable-leg-curl.md)（優先） |
| 固定できない / 自重 | スライディング・レッグカール（[自重のみ版](../programs/variants/bodyweight-only.md)） |
| ハムに違和感 | RDL のみに頼らず、軽いスライディング・レッグカールで ROM を確保 |

## 豆知識
- エキセントリックのテンポを遅くするのはこの種目の性質上の話で、「全種目3秒エキセントリック必須」という意味ではない。
