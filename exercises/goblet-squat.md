# ゴブレットスクワット（Goblet Squat）

| 項目 | 内容 |
| --- | --- |
| 部位 | 脚 |
| 主働筋 | 大腿四頭筋、大臀筋 |
| 補助筋 | 内転筋群、脊柱起立筋・腹筋群（体幹の固定）、上腕・前腕（重りの保持） |
| 器具 | ダンベル1個 / ケトルベル1個 |
| 難易度 | ★☆☆ |
| 動作パターン | スクワット |
| 推奨レップ | 10〜12 |
| 推奨RIR | 3〜4 |
| テンポ | 2–0–X–0 |
| 登場プログラム | [はじめての3週間](../guide/first-3-weeks.md#メニュー)（Day A / Day B） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Legs A：ヒールエレベーテッド / Legs B） |

## なぜやるのか
重りを胸の前で抱えるので、前に重心が乗り、体を起こしたまましゃがみやすい。
バーベルを担ぐスクワットより腰が丸まりにくく、しゃがむ動作そのものを覚えるのに向く。
ダンベル1個あればジムでも自宅でもでき、器具の制約を受けにくい。

## やり方
1. ダンベルを縦にして、両手で上側のプレートを下から包むように持ち、胸の前（鎖骨の下）に当てる。肘は体の前で下に向ける
2. 足は肩幅〜やや広め、つま先は軽く外向きにする
3. 胸を起こし、腹圧を入れて背骨を中立に保つ
4. 2秒かけて、膝とつま先を同じ方向に向けたまま、腰が丸まらない範囲で深くしゃがむ。肘が膝の内側に入るくらいが目安
5. 底で止めずに、足裏全体で床を押して立ち上がる。膝は伸ばし切る手前で止める

## よくあるミス
- 重りが体から離れ、前に引っ張られて背中が丸まる
- 膝が内側に入る
- 踵が浮いてつま先立ちになる
- 深さが浅く、しゃがむ練習になっていない
- 重すぎて腕で支えきれず、フォームより先に腕が限界になる

## 初心者向けのコツ
- 最初は重りなし、または 4〜8kg 程度から。脚より先に腕が疲れるなら重すぎる
- 踵が浮く・深くしゃがめない場合は、踵の下に薄いプレートや板（2〜3cm）を置くと楽になる。ダンベルのみ版の「ヒールエレベーテッド」はこの形
- 深さは「腰が丸まらない範囲」で決め、毎回同じ深さにする
- 膝・腰に痛みが出たら中止し、足幅・つま先の向き・深さを見直す

## 代替種目
| 状況 | 代替 |
| --- | --- |
| マシンがあり、まず脚の力だけに集中したい | [レッグプレス](leg-press.md) |
| 片手で持てる重さでは軽すぎる | [スミスマシン・スクワット](smith-squat.md) / [ブルガリアンスプリットスクワット](bulgarian-split-squat.md) |
| 自重 | 自重スクワット（手を胸の前で組む） |
| 膝に違和感 | 深さを浅くする。それでも痛むなら [レッグプレス](leg-press.md) で ROM を調整 |

## 豆知識
- 名前の由来は、重りを「ゴブレット（脚付きの杯）」を抱えるように持つ形から。
- 片手で扱えるダンベルの重さには上限があるので、12回で RIR 3〜4 に収まらなくなったら、重さを足すより [スミスマシン・スクワット](smith-squat.md) か [ブルガリアンスプリットスクワット](bulgarian-split-squat.md) に進む方が続けやすい。
