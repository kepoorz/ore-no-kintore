| 項目 | 内容 |
| --- | --- |
| 部位 | 脚 |
| 主働筋 | ハムストリングス（膝屈曲） |
| 補助筋 | 腓腹筋 |
| 器具 | クロスオーバーケーブル + 足首カフ |
| 難易度 | ★★☆ |
| 動作パターン | 膝屈曲 |
| 推奨レップ | 8〜15 |
| 推奨RIR | 1〜2 |
| テンポ | 2–1–1–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Legs B：膝屈曲ハム種目の優先1） / [4日](../programs/4-day.md)（Lower B） / [5日](../programs/5-day.md)（Lower / Legs） / [3日](../programs/3-day.md)（Full A） |

## なぜやるのか
このジムにはレッグカールマシンがなく、膝屈曲のハム種目が最大の穴になっている。
足首カフがあれば、ケーブルでマシンに近い膝屈曲を作れる。RDL（股関節伸展）と組み合わせてハムを完結させる。

## やり方
1. プーリーを最下部にセットし、足首カフを片足に巻く
2. マシンのフレームを持ってケーブルに向かって立つ（うつ伏せで行える環境ならそれでもよい）
3. 太腿を床と垂直に保ち、骨盤を動かさない
4. 踵を尻に近づけるように膝を曲げ、上で1秒止める
5. 2秒かけて膝が伸び切るまで戻し、1秒止める

## よくあるミス
- 太腿が前後に動き、股関節で振り上げる
- 腰を反らして ROM をごまかす
- 戻しで張力を抜く

## 初心者向けのコツ
- 軽い重量・RIR3〜4 で、太腿を固定する感覚を先に覚える
- 立位でふらつく場合はフレームをしっかり持つ
- 膝裏・腰に痛みや攣りが出たら中止する

## 代替種目
| 状況 | 代替 |
| --- | --- |
| 足首カフがない | [Nordic ハムストリングカール](nordic-hamstring-curl.md)（足首を安全に固定できる場合） |
| ダンベルのみ / 自重 | スライディング・レッグカール（[自重のみ版](../programs/variants/bodyweight-only.md)） |
| 最後の手段 | うつ伏せ DB レッグカール（足で安全に保持できる軽重量のみ） |

## 豆知識
- 股関節伸展（RDL）と膝屈曲（レッグカール）では、ハムの部位ごとの適応が異なる [[Morin 2025]](../basics/references.md#morin-2025)。両方を残すのがこの wiki の方針。
