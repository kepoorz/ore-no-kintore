# コペンハーゲン・プランク（Copenhagen Plank）

| 項目 | 内容 |
| --- | --- |
| 部位 | コア |
| 主働筋 | 内転筋群、内腹斜筋・外腹斜筋 |
| 補助筋 | 腰方形筋、中臀筋（下側の脚） |
| 器具 | 自重 + ベンチ |
| 難易度 | ★★★ |
| 動作パターン | コア・抗側屈（置き換え表の対象外） |
| 推奨レップ | 20〜40秒 / 側 |
| 推奨RIR | RPE8 |
| テンポ | 静止 |
| 登場プログラム | [6日](../programs/6-day.md)（Legs B） / [4日](../programs/4-day.md)（Lower B） / [5日](../programs/5-day.md)（Legs） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Legs B） / [自重のみ](../programs/variants/bodyweight-only.md)（Legs B） |

## なぜやるのか
横向きに体を支える「抗側屈」と、直接種目が少ない内転筋を同時に鍛えられる。
内転筋は深いスクワットやランジ以外で刺激が少なく、この種目で補う。

## やり方
1. ベンチの横に横向きで寝て、下側の肘を肩の真下につく
2. 上側の脚をベンチに乗せる（膝を乗せると簡単、足首を乗せると難しい）
3. 上側の脚でベンチを押し、腰を持ち上げて頭から足までを一直線にする
4. 下側の脚は床から浮かせるか、軽く添える
5. RPE8 に達するまで保持し、反対側も同じ時間行う

## よくあるミス
- 腰が落ちて体が「く」の字になる
- 体が前後に倒れる
- 最初から足首を乗せる難しい版で行い、鼠径部を痛める

## 初心者向けのコツ
- 最初は膝をベンチに乗せた短いレバー版、10〜20秒から
- 導入期は RPE6〜7 程度で止める
- 鼠径部や膝の内側に痛みが出たら直ちに中止する

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ベンチがない | 通常のサイドプランク（抗側屈のみ） |
| 難しすぎる | 膝乗せ版 / 時間を短くする |
| 鼠径部に違和感 | サイドプランクに替え、内転筋は [ブルガリアンスプリットスクワット](bulgarian-split-squat.md) などで補う |

## 豆知識
- 内転筋の強化はスポーツ領域で鼠径部の故障予防目的にも使われる種目だが、予防効果を断定するものではない。内転筋のエキセントリック筋力を大きく高めた研究がある [[Ishøi 2016]](../basics/references.md#ishoi-2016)。
