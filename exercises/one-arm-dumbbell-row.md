# ワンハンド・ダンベルロー（One-Arm Dumbbell Row）

| 項目 | 内容 |
| --- | --- |
| 部位 | 背中 |
| 主働筋 | 広背筋 |
| 補助筋 | 僧帽筋中部、菱形筋、後部三角筋、上腕二頭筋 |
| 器具 | ダンベル、フラットベンチ |
| 難易度 | ★☆☆ |
| 動作パターン | 水平プル |
| 推奨レップ | 8〜12 / 側 |
| 推奨RIR | 2（第一種目） / 1〜2 |
| テンポ | 2–1–X–0 |
| 登場プログラム | [ダンベルのみ](../programs/variants/dumbbell-only.md)（Pull A / B） |

## なぜやるのか
ダンベルだけの環境で広背筋に重い負荷をかける主力。
片側ずつなので重いダンベルが1つあれば成立し、肩甲骨の可動域も広く取れる。

## やり方
1. ベンチに片手・片膝をつき、反対の足は床につけて体を安定させる
2. 背骨を中立にし、ダンベルを肩の真下に垂らす
3. 肘を腰の方向へ弧を描くように引く
4. 上で1秒止める
5. 2秒かけて肩甲骨が前に出るまで下ろす
6. 左右同じ回数を行う

## よくあるミス
- 体幹をひねって反動で上げる
- 肘を真上に引き、上腕二頭筋の種目になる
- 背中が丸まり、腰に負担がかかる
- 片側だけ回数を多くして左右差を広げる

## 初心者向けのコツ
- 導入期は RIR3〜4 の軽い重量で、体幹を動かさずに引けるか確認する
- 弱い側から始め、その回数に強い側を合わせる
- 腰や肩に痛みが出たら中止し、重量を下げる
