# ヒップリフト / グルートブリッジ（Glute Bridge）

| 項目 | 内容 |
| --- | --- |
| 部位 | 脚 |
| 主働筋 | 大臀筋 |
| 補助筋 | ハムストリングス、腹筋群（骨盤の固定） |
| 器具 | 自重（床・マット）。慣れたらダンベル / プレートを骨盤に乗せる |
| 難易度 | ★☆☆ |
| 動作パターン | 股関節伸展（置き換え表の対象外。ヒップヒンジの補完） |
| 推奨レップ | 12〜15 |
| 推奨RIR | 3〜4 |
| テンポ | 2–1–X–1 |
| 登場プログラム | [はじめての3週間](../guide/first-3-weeks.md#メニュー)（Day B） |

## なぜやるのか
床に寝た状態で腰を持ち上げ、股関節を伸ばし切る位置で大臀筋を使う。
腰に負担がかかりにくく、器具がいらないので、初心者が「お尻で押す」感覚を覚える最初の種目に向く。
座っている時間が長いと臀筋は使われにくくなる。スクワットや RDL でお尻の感覚が分からない人は、まずここで覚える。

## やり方
1. 床に仰向けになり、膝を曲げて足を腰幅に開く。踵は尻から 30cm 前後、トップで膝が約90°になる位置に置く
2. 腕は体の横に置き、顎を軽く引いて肋骨を締める
3. 踵で床を押し、股関節を伸ばし切るまで腰を持ち上げる。膝・股関節・肩が一直線になるのがトップ
4. トップで1秒止め、臀筋を締める。腰を反らせて高さを稼がない
5. 2秒かけて下ろし、尻が床に触れる手前で1秒止めて次のレップへ

## よくあるミス
- トップで腰を反らして「上がった」つもりになる（腰で持ち上げている）
- 足が遠すぎてハムストリングスに逃げる、近すぎて四頭に逃げる
- つま先で押して踵が浮く
- 勢いで上げ下げし、トップで止まらない

## 初心者向けのコツ
- 最初は自重で、トップでお尻が硬く締まる感覚を探す。腰やハムに張りを感じるなら足の位置をずらす
- 15回で RIR 3〜4 に収まらなくなったら、骨盤の上にダンベルやプレートを乗せる。次は片脚版
- 腰に痛みが出たら中止し、トップで反りすぎていないか・顎が上がっていないかを確認する

## 代替種目
| 状況 | 代替 |
| --- | --- |
| 自重では軽すぎる | 重りを骨盤に乗せる / シングルレッグ・グルートブリッジ |
| ジムでさらに負荷を上げたい | [ヒップスラスト](hip-thrust.md) |
| ハムも一緒に鍛えたい | [ルーマニアン・デッドリフト](romanian-deadlift.md)（軽めで） |
| 腰に違和感 | ROM を小さくし、トップで反らない。それでも痛むなら中止 |

## 豆知識
- **ヒップスラストとの違い**：グルートブリッジは背中を床につけて行い、ヒップスラストは肩甲骨の下をベンチに乗せて行う。ベンチの高さの分だけ股関節の可動域が大きく、重いバーを乗せやすいので、ヒップスラストは負荷を伸ばす段階の種目、グルートブリッジは動作を覚える・自宅でやる段階の種目、と位置づけると分かりやすい。狙う筋肉は同じ大臀筋で、やり方の注意点もほぼ共通する
- 自重のグルートブリッジは大臀筋の「ウォームアップ」としても使える。脚の日の最初に 10〜15回入れると、スクワットや RDL でお尻を使う感覚が出やすいと感じる人が多い（筆者の経験。一般化はしない）
