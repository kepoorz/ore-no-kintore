# ペックデック（Pec Deck）

| 項目 | 内容 |
| --- | --- |
| 部位 | 胸 |
| 主働筋 | 大胸筋 |
| 補助筋 | 前部三角筋 |
| 器具 | ペックデックマシン |
| 難易度 | ★☆☆ |
| 動作パターン | 胸アイソレーション（水平内転。置き換え表の対象外） |
| 推奨レップ | 10〜15 |
| 推奨RIR | 1 |
| テンポ | 2–1–1–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Push B） / [5日](../programs/5-day.md)（Push） |

## なぜやるのか
軌道が固定されたフライで、体幹の安定をほぼ要求せずに大胸筋を狙える。
フォームの再現性が高く、アイソレーションとして重量・回数の進歩を追いやすい。

## やり方
1. シート高を、グリップ（またはパッド）が胸の高さに来るよう調整する
2. 背もたれに背中をつけ、肩甲骨を軽く寄せて下げる
3. 肘を軽く曲げたまま、腕を胸の前で寄せる
4. 寄せた位置で1秒止める
5. 2秒かけて胸のストレッチを感じる位置まで戻し、1秒止める

## よくあるミス
- 肩がすくみ、首や僧帽筋に効いてしまう
- 戻しで開きすぎて肩の前に負担がかかる
- 背中が背もたれから離れ、反動で寄せる

## 初心者向けのコツ
- RIR3〜4 の軽い重量でシート高とスタート位置を決め、記録する
- 「腕で引く」より「肘を内側に寄せる」意識の方が胸に入りやすい
- 肩に痛みが出たら中止し、スタート位置の開きを小さくする

## 豆知識
- 同じマシンで向きを変えると [リバースペックデック](reverse-pec-deck.md) になる機種が多い。
- 安全なマシン種目なので、最終セットだけ任意で RIR0 にする選択肢がある。
