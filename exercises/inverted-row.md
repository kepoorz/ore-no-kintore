# インバーテッドロー（Inverted Row）

| 項目 | 内容 |
| --- | --- |
| 部位 | 背中 |
| 主働筋 | 広背筋、僧帽筋中部、菱形筋 |
| 補助筋 | 後部三角筋、上腕二頭筋、腹筋群・臀筋（体幹の固定） |
| 器具 | 自重（低いバー / スミスバー / 頑丈なテーブル） |
| 難易度 | ★★☆ |
| 動作パターン | 水平プル |
| 推奨レップ | 6〜15 |
| 推奨RIR | 2（第一種目） / 1〜2 |
| テンポ | 2–1–X–0 |
| 登場プログラム | [自重のみ](../programs/variants/bodyweight-only.md)（Pull A / B） |

## なぜやるのか
自重で「引く」動作を負荷付きで行える数少ない種目。自重版の Pull 日の土台になる。
足の位置と体の角度で難易度を細かく調整できる。

## やり方
1. 腰の高さ前後のバーの下に仰向けで入り、肩幅程度で握る
2. 踵を床につけ、頭から踵までを一直線にする
3. 肩甲骨を寄せながら胸をバーへ引き寄せる
4. 上で1秒止める
5. 2秒かけて腕が伸びるまで下ろす

## よくあるミス
- 腰が落ち、体が「く」の字になる
- 顎だけバーに近づけて ROM をごまかす
- 固定が不確かな家具を使う

## 初心者向けのコツ
- 体を起こし気味（バーを高く）にすると簡単になる。膝を曲げても可
- 導入期は RIR3 程度。体幹が一直線のまま引ける回数を記録する
- テーブル等を使う場合、体重をかけても動かないことを必ず確認する。不安なら行わない
- 肩・肘に痛みが出たら中止する

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ジム | [ロングプル](long-pull.md) |
| ダンベルのみ | [ワンハンド DB ロー](one-arm-dumbbell-row.md) |
| 簡単すぎる | 足上げインバーテッドロー / 上でのホールドを延ばす |
| 狙いを変える | 肘を腰へ（広背筋寄り） / 肘を開く（上背部寄り） / アンダーハンド（二頭も） |

## 豆知識
- 自重版は広背筋・二頭が弱くなりやすい。Pull 日はこの種目ができる環境を確保するのが前提。
