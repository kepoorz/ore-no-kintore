# 種目図鑑

プログラムに登場する種目を、1種目1ページ・同じフォーマットでまとめた図鑑。

## このページの使い方

- 部位別の表から種目を探し、右端のリンクで個別ページへ飛ぶ
- 各ページの上部の表で「器具・難易度・推奨レップ・RIR・テンポ・登場プログラム」をまとめて確認できる
- 器具がない・痛みがある時は、各ページの「代替種目」を見る。置き換えは同じ動作パターンの中で行う（[置き換え表](../programs/README.md)）
- 難易度：★☆☆ = フォームを覚えやすい / ★★☆ = 少し練習が要る / ★★★ = 習得に時間がかかる・慎重に始める
- 推奨レップ・RIR・テンポは [6日版](../programs/6-day.md) を基準にしている。食い違う場合はプログラム側を優先する
- 痛みが出たら中止する。このWikiは医療的な判断の代わりにはならない

## 新しい種目を追加するには

1. [../templates/pages/exercise.md](../templates/pages/exercise.md) をコピーし、`exercises/英語kebab-case.md` として保存する
2. 見出し名は変えずに中身を埋める。存在しないページへのリンクは作らない
3. このページの該当部位の表に1行追加する
4. 「編集履歴・コメント」に変更内容を1行書く
