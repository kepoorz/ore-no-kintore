# ケーブルフライ（Cable Fly）

| 項目 | 内容 |
| --- | --- |
| 部位 | 胸 |
| 主働筋 | 大胸筋（High→Low は胸骨部寄り） |
| 補助筋 | 前部三角筋 |
| 器具 | クロスオーバーケーブル |
| 難易度 | ★★☆ |
| 動作パターン | 胸アイソレーション（水平内転。置き換え表の対象外） |
| 推奨レップ | 10〜15 |
| 推奨RIR | 1 |
| テンポ | 2–1–1–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Push A：High→Low） |

## なぜやるのか
プレスで疲れた後に、三頭の関与を減らして大胸筋だけに負荷をかける仕上げ種目。
ケーブルは可動域の端でも張力が抜けにくく、ストレッチ位とコントラクト位の両方で負荷が乗る。

## やり方
1. プーリーを肩より上にセットし、ハンドルを持って一歩前に出る（High→Low）
2. 片足を前に出して体幹を安定させ、肘を軽く曲げて固定する
3. 2秒かけて腕を開き、胸のストレッチを感じる位置で1秒止める
4. 肘の角度を変えずに、手を下腹部の前へ弧を描いて寄せる
5. 寄せた位置で1秒止め、ゆっくり戻す

## よくあるミス
- 肘を曲げ伸ばしして、プレス動作になる
- 開きすぎて肩の前が引っ張られる
- 重すぎて上半身ごと前に倒れ込む
- 戻しで張力を抜き、勢いで次のレップに入る

## 初心者向けのコツ
- 軽い重量・RIR3〜4 で、肘の角度を固定する感覚を先に覚える
- ストレッチは「肩が痛くない範囲」で止める
- 肩の前に痛みが出たら中止し、開く幅を小さくする

## 豆知識
- プーリーの高さで胸のどこにバイアスがかかるかが変わる。ただし特定部位だけに切り替わるわけではない。
- フライ系は重量より「張力が抜けない ROM」を優先した方が記録が安定しやすい。
