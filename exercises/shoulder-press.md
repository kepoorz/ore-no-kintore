# ショルダープレス（Shoulder Press）

| 項目 | 内容 |
| --- | --- |
| 部位 | 肩 |
| 主働筋 | 前部三角筋、中部三角筋 |
| 補助筋 | 上腕三頭筋、僧帽筋上部・前鋸筋 |
| 器具 | ショルダープレスマシン / ダンベル |
| 難易度 | ★☆☆（マシン） / ★★☆（ダンベル） |
| 動作パターン | 垂直プッシュ |
| 推奨レップ | 8〜12 |
| 推奨RIR | 1〜2 |
| テンポ | 2–0–X–0 |
| 登場プログラム | [6日](../programs/6-day.md)（Push A：マシン / Push B：DB or マシン） / [5日](../programs/5-day.md)（Push） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Push A / B） |

## なぜやるのか
肩を頭上方向へ押す動作で、三角筋に重い負荷をかける。
胸プレスで前部三角筋はかなり使われるため、ここでは2セット程度に抑えて中部三角筋の補完役とする。

## やり方
1. マシンはグリップが肩の高さ付近に来るようシート高を調整する（DB はベンチを 80〜90° に）
2. 背もたれに背中をつけ、肋骨を締めて腰の反りを抑える
3. 前腕を床と垂直に保ったまま、頭上へ押し上げる
4. 肘を伸ばし切る手前〜伸ばし切るまで押す
5. 2秒かけて耳〜顎の高さまでコントロールして下ろす

## よくあるミス
- 腰を大きく反らし、インクラインプレスになる
- 肘が前腕より内側・外側に崩れる
- DB で下ろしが浅く、ROM が日によって違う
- 首をすくめて押す

## 初心者向けのコツ
- 最初はマシンから。RIR3〜4 でシート高を決めて記録する
- DB は持ち上げ（膝で蹴って肩へ）を軽い重量で練習する
- 肩に痛みが出たら中止し、手の向きをニュートラルにする・ROM を浅くするなどを試す

## 代替種目
| 状況 | 代替 |
| --- | --- |
| ダンベルのみ | DB ショルダープレス |
| 自重 | パイクプッシュアップ（[自重のみ版](../programs/variants/bodyweight-only.md)） |
| 肩に違和感 | [ラテラルレイズ](lateral-raise.md) で中部三角筋を補う |

## 豆知識
- 週の前部三角筋への直接セットは少なくても、胸プレスから多くの刺激が入る。前肩を増やす前に中部・後部の不足を疑う。
