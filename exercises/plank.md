# プランク（Plank）

| 項目 | 内容 |
| --- | --- |
| 部位 | コア |
| 主働筋 | 腹直筋、腹横筋 |
| 補助筋 | 内腹斜筋・外腹斜筋、大臀筋、前鋸筋、肩周り（支持） |
| 器具 | 自重（床・マット） |
| 難易度 | ★☆☆ |
| 動作パターン | コア・抗伸展（置き換え表の対象外） |
| 推奨レップ | 20〜30秒 |
| 推奨RIR | 余裕を残す（姿勢が崩れる前に止める） |
| テンポ | 静止 |
| 登場プログラム | [はじめての3週間](../guide/first-3-weeks.md#メニュー)（Day A） |

## なぜやるのか
肘とつま先で体を支え、頭から踵までを一直線に保つ。腰が反る方向に耐える「抗伸展」の基本種目。
器具がいらず、やり方が単純で、腰への負担が小さい。初心者が「体幹を固める」とはどういう感覚かを覚える入口になる。
スクワットや RDL で背中を丸めない・反らさないために必要な、同じ能力を使う。

## やり方
1. うつ伏せになり、肘を肩の真下につく。前腕は床に平行にし、手は軽く握るか床に置く
2. つま先を立てて体を持ち上げ、頭・肩・腰・膝・踵が一直線になるようにする
3. 臀筋を締め、へそを軽く背骨側へ引き、腰が反らないようにする
4. 視線は手の少し前の床。首を反らせない
5. 呼吸を止めずに、姿勢を保てる時間だけ保持する。腰が落ち始めたら終了する

## よくあるミス
- 腰が落ちて反る（最も多い。腹筋ではなく腰で支えている）
- 尻を高く上げて楽をする
- 息を止める
- 時間だけを目標にして、崩れた姿勢で何分も続ける

## 初心者向けのコツ
- 20秒保てないなら、膝をついた版から。膝から頭までを一直線にすれば狙いは同じ
- 「余裕を残す」とは、姿勢が崩れる前に止めるということ。崩れた姿勢で粘るより、短く正しく2セットの方がよい
- 鏡か動画で横から見て、腰が落ちていないかを一度確認する
- 腰に痛みが出たら中止し、臀筋を締めて骨盤をわずかに後傾させてみる。それでも痛むなら [デッドバグ](dead-bug.md) に替える

## 代替種目
| 状況 | 代替 |
| --- | --- |
| 20秒保てない | 膝つきプランク / 手を台につくインクライン・プランク |
| 30秒が楽になった | [RKC プランク](rkc-plank.md)（全身で力む版） |
| うつ伏せの姿勢がつらい | [デッドバグ](dead-bug.md) |
| 腰に違和感 | [デッドバグ](dead-bug.md) で腰を床につけたまま同じ機能を鍛える |

## 豆知識
- **RKC プランクへの進み方**：普通のプランクで 30秒が余裕を持って保てるようになったら、時間を伸ばすのではなく、臀筋を強く締め・骨盤をわずかに後傾させ・肘をつま先側へ引き寄せるように床を押して「全身で力む」[RKC プランク](rkc-plank.md) に進む。短時間で負荷を上げられ、2分・3分と時間を延ばすより管理しやすい。この wiki の各プログラムでは RKC 版を採用している
- 静止種目は RIR が使いにくい。慣れてきたら、プログラム側で使っている RPE（主観的なきつさ、0〜10）で管理する。「余裕を残す」は RPE 6〜7 程度の感覚と考えてよい
