# RKC プランク（RKC Plank）

| 項目 | 内容 |
| --- | --- |
| 部位 | コア |
| 主働筋 | 腹直筋、腹横筋 |
| 補助筋 | 内腹斜筋・外腹斜筋、大臀筋、前鋸筋 |
| 器具 | 自重（床・マット） |
| 難易度 | ★★☆ |
| 動作パターン | コア・抗伸展（置き換え表の対象外） |
| 推奨レップ | 20〜40秒 |
| 推奨RIR | RPE8 |
| テンポ | 静止 |
| 登場プログラム | [6日](../programs/6-day.md)（Pull A） / [4日](../programs/4-day.md)（Lower A） / [5日](../programs/5-day.md)（Lower） / [ダンベルのみ](../programs/variants/dumbbell-only.md)（Pull A） / [自重のみ](../programs/variants/bodyweight-only.md)（Pull A） |

## なぜやるのか
通常のプランクを全身で強く力んで行う版で、短時間で腹部に高い負荷をかけられる。
腰が反る方向に耐える「抗伸展」を担当する。

## やり方
1. 肘を肩の真下よりやや前につき、つま先で体を支える
2. 頭から踵までを一直線にする
3. 臀筋を強く締め、骨盤をわずかに後傾させる
4. 肘をつま先側へ引き寄せるように床を押し、全身を力ませる
5. 呼吸を止めずに、RPE8 に達するまで保持する

## よくあるミス
- 腰が落ちて反る
- 尻を高く上げて楽をする
- 息を止め続ける
- 2分以上ゆるく続けて、負荷が上がらない

## 初心者向けのコツ
- 最初は10〜20秒からでよい。通常のプランクより短く感じるのが正常
- 膝をついた版から始めてもよい
- 腰に痛みが出たら中止し、骨盤の位置を見直す

## 代替種目
| 状況 | 代替 |
| --- | --- |
| 簡単すぎる | ロングレバー・プランク（肘をさらに前につく） |
| 腰に違和感 | DB デッドバグ（[ダンベルのみ版](../programs/variants/dumbbell-only.md)） |
| 屈曲も鍛えたい | [ケーブルクランチ](cable-crunch.md) |

## 豆知識
- 静止種目は RIR が使いにくいので RPE で管理する。RPE8 は「あと少し耐えられるが、フォームを保てる限界が近い」程度。
