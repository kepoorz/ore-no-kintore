| 項目 | 内容 |
| --- | --- |
| 部位 | コア |
| 主働筋 | 腹直筋 |
| 補助筋 | 内腹斜筋・外腹斜筋 |
| 器具 | クロスオーバーケーブル（ロープ） |
| 難易度 | ★★☆ |
| 動作パターン | コア・屈曲（置き換え表の対象外） |
| 推奨レップ | 8〜15 |
| 推奨RIR | 1〜2 |
| テンポ | 2–1–1–1 |
| 登場プログラム | [6日](../programs/6-day.md)（Push A） / [4日](../programs/4-day.md)（Upper A） / [5日](../programs/5-day.md)（Push） / [3日](../programs/3-day.md)（Full A） |

## なぜやるのか
腹直筋に外部負荷をかけ、他の筋と同じように重量・回数で進歩を管理できる。
自重クランチを何十回も続けるより、8〜15回で RIR1〜2 になる負荷の方が記録を追いやすい。

## やり方
1. プーリーを高い位置にセットし、ロープを頭の横で持って膝立ちになる
2. 尻をかかとから少し浮かせ、股関節の角度を固定する
3. 肋骨を骨盤に近づけるように背中を丸めていく
4. 丸め切った位置で1秒止める
5. 2秒かけて背中を伸ばし、上で1秒止める

## よくあるミス
- 股関節を曲げて上体ごと倒れ込み、腹筋が丸まっていない
- 腕でロープを引き下ろす
- 首だけを曲げる

## 初心者向けのコツ
- 軽い重量・RIR3〜4 で、「背骨を丸める」感覚を先に覚える
- ロープの位置は頭の横で固定し、腕は動かさない
- 腰や首に痛みが出たら中止し、重量を下げて ROM を小さくする

## 豆知識
- コアは「屈曲 / 抗伸展 / 抗回旋 / 抗側屈」の4機能で分けて週に配置している。この種目は屈曲担当。
