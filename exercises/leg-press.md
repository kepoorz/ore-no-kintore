# レッグプレス（Leg Press）

| 項目 | 内容 |
| --- | --- |
| 部位 | 脚 |
| 主働筋 | 大腿四頭筋、大臀筋 |
| 補助筋 | ハムストリングス、内転筋群 |
| 器具 | レッグプレスマシン（45°スレッド型 / 水平シート型） |
| 難易度 | ★☆☆ |
| 動作パターン | スクワット |
| 推奨レップ | 10〜12 |
| 推奨RIR | 3〜4 |
| テンポ | 2–0–X–0 |
| 登場プログラム | [はじめての3週間](../guide/first-3-weeks.md#メニュー)（Day A） |

## なぜやるのか
背中をシートに預けた状態で脚を押すので、バランスや体幹の固定に気を取られず、四頭と臀筋に負荷をかけることだけに集中できる。
スクワットの前段階として、初心者が「脚で重いものを押す」感覚と、記録して重さを伸ばす習慣を覚えるのに向く。
マシンの設定を毎回同じにすれば、重さと回数の伸びがそのまま進歩の記録になる。

## やり方
1. **シートの位置を決める。** 足を乗せた状態で膝が約90°まで曲がり、底で尻がシートから浮かない位置に背もたれ（またはシート）を調整する。数字が付いていれば記録する
2. **足を置く。** 足は肩幅前後、プレートの中央〜やや上に、つま先は軽く外向き。踵がプレートから浮かないようにする
3. **セーフティストッパーを設定する。** 底まで下ろしたときに潰れても止まる位置にセットする。初回は必ず空（最小重量）で動作を確認する
4. 足裏全体でプレートを押し、膝を伸ばしてからロックレバーを外す。膝は伸ばし切らず、わずかに曲げておく
5. 2秒かけて、腰がシートから浮かない範囲で膝を曲げていく
6. 底で止めずに、踵と足裏全体で押し戻す。トップで膝を完全に伸ばし切ってロックしない
7. 終わったら膝を伸ばした位置でロックレバーを掛けてから足を降ろす

## よくあるミス
- 深く下ろしすぎて、底で尻や腰がシートから浮く（腰が丸まり、負担が集まる）
- トップで膝を伸ばし切り、関節に体重をかけて休む
- 踵が浮いてつま先だけで押す
- 膝が内側に入る
- セーフティを外したまま、またはロックを掛けずに乗り降りする
- 毎回シート位置や足の位置が違い、記録が比較できない

## 初心者向けのコツ
- 1回目はプレートを載せない空の状態で、シート位置・足の位置・ストッパー位置を決めて記録する。以後は毎回同じにする
- 「あと3〜4回できる」で止める。レッグプレスは重さを載せやすいが、最初の3週間は重さの伸びより ROM とフォームの安定を優先する
- 回数が12回に届いたら、次回は1枚（最小単位）だけ重くする
- 膝や腰に痛みが出たら中止し、下ろす深さを浅くする・足の位置を少し上にずらす・重量を下げる、の順で試す

## 代替種目
| 状況 | 代替 |
| --- | --- |
| マシンがない | [ゴブレットスクワット](goblet-squat.md) |
| ジムに慣れてきた | [スミスマシン・スクワット](smith-squat.md) |
| ダンベルのみ | [ゴブレットスクワット](goblet-squat.md) / [ブルガリアンスプリットスクワット](bulgarian-split-squat.md) |
| 自重 | 自重スクワット（椅子に腰を軽く触れる深さまで） |
| 膝に違和感 | ROM を浅くする。それでも痛むなら [レッグエクステンション](leg-extension.md) を軽い重量で |

## 豆知識
- 足を置く位置を高くすると臀筋・ハム寄り、低くすると四頭寄りに負荷が移るとされる。ただし低すぎると膝への負担が増えるので、初心者はプレート中央〜やや上で固定し、位置を変えるのは慣れてからでよい。
- 45°スレッド型と水平シート型では同じ「重量」でも体感がまったく違う。マシンが変わったら記録は別物として扱い、比べない。
- この wiki の [6日版](../programs/6-day.md) は、筆者のジムにレッグプレスがないためスミスマシン・スクワットを主力にしている。レッグプレスがあるジムでは、スクワット系の置き換え先として使ってよい。
