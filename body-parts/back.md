# 背中（広背筋・上背部）

| 項目 | 内容 |
| --- | --- |
| 週の直接セット | 広背筋 約11 / 上背部（僧帽筋中部・菱形筋）約8〜11 |
| 頻度 | 週2回 |
| 主な動作 | 垂直プル、水平プル |

## 構成の考え方

- **垂直プル（プルダウン）と水平プル（ロー）の両方** を入れる
- ローは肘の軌道で負荷配分が変わる
  - 肘を体側〜腰へ → 広背筋寄り
  - 肘を開いて胸へ → 上背部・リアデルト寄り
- プルダウンの手幅は極端に広くしない。肩幅〜1.5倍で、大きな可動域を優先 [[Andersen 2014]](../basics/references.md#andersen-2014)

## 主な種目

| 役割 | 種目 |
| --- | --- |
| 垂直プル | [ラットプルダウン](../exercises/lat-pulldown.md) |
| 水平プル | [ロングプル](../exercises/long-pull.md) / [チェストサポート DB ロー](../exercises/chest-supported-dumbbell-row.md) / [ワンハンド DB ロー](../exercises/one-arm-dumbbell-row.md) |
| 補助 | [ストレートアーム・プルダウン](../exercises/straight-arm-pulldown.md) |
| 自重 | [インバーテッドロー](../exercises/inverted-row.md) |

## 注意

- 腰が疲れやすいならチェストサポート系を選ぶ
- 自重だけで背中を十分に鍛えるのは難しい。低いバーか頑丈なテーブルでインバーテッドローを確保する
