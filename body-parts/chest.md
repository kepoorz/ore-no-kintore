# 胸（大胸筋）

| 項目 | 内容 |
| --- | --- |
| 週の直接セット | 10〜15（6日版は15） |
| 頻度 | 週2回 |
| 主な動作 | 水平プッシュ、上胸（インクライン）、フライ |

## 構成の考え方

- **プレス系を軸** にし、フライ系で補う
- 上胸はインクライン 25〜40°。30°固定にこだわらず（30°の根拠は筋電図研究 [[Rodríguez-Ridao 2020]](../basics/references.md#rodriguez-ridao-2020)）、肩が快適な角度を記録して毎回同じ設定で進歩を測る
- プレスは前部三角筋と三頭筋にも効く（間接セット）。肩・腕のセットを数えるときに考慮する

## 主な種目

| 役割 | 種目 |
| --- | --- |
| メイン | [スミス・ベンチプレス](../exercises/smith-bench-press.md) / [チェストプレス](../exercises/chest-press-machine.md) |
| 上胸 | [インクライン DB プレス](../exercises/incline-dumbbell-press.md) |
| 補助 | [ケーブルフライ](../exercises/cable-fly.md) / [ペックデック](../exercises/pec-deck.md) |

## 注意

- 肩の前に痛みが出るなら、角度・グリップ幅・可動域を見直す
- ラックとセーフティがない環境では、高重量のフリーベンチはやらない
