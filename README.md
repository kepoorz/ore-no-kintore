## このリポジトリについて

筆者が筋トレにハマったことをきっかけに作ったリポジトリ。
実際にやってきたトレーニングや食事の内容、その裏にある理論、AI（Claude ほか）と壁打ちして出た結論を、ここにまとめていく。

- **参加自由**：誤字の修正、種目の追加、体験談、反論まで、誰でも Issue / PR を送っていい → [編集ガイド](CONTRIBUTING.md)
