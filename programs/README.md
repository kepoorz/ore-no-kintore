# プログラムの選び方

**継続できる日数** で選ぶ。多いほど良いわけではない。分割法そのものに優劣はなく、週のボリュームをどう分散するかの違い。

| 週の日数 | 分割 | 部位あたり頻度 | 位置づけ |
| --- | --- | --- | --- |
| [6日](6-day.md) | PPL × 2 | 週2回 | **ベース文書**（自分が実際に回しているもの） |
| [5日](5-day.md) | Upper / Lower + PPL | 週約2回 | 6日版から1日減らした派生 |
| [4日](4-day.md) | Upper / Lower × 2 | 週2回 | 多くの人に現実的 |
| [3日](3-day.md) | 全身 × 3 | 週3回 | 忙しい時期・導入期 |

ジムに行けない日の互換版：

| 版 | 用途 | 6日版との互換性 |
| --- | --- | --- |
| [ダンベルのみ](variants/dumbbell-only.md) | ダンベルしかない簡易ジム | 高 |
| [自重のみ](variants/bodyweight-only.md) | ホテル・出張先 | 中（Pull・中部三角筋が弱い） |

## 共通ルール

- 表記：`セット × 回数 @RIR`。RPE はプランク等の静止種目に使う
- ダブルプログレッション：全セットでレンジ上限に到達したら最小の刻みで増量
- 新しいプログラムの最初の2週は導入期（[04-training-principles.md](../basics/training-principles.md#導入期新しいプログラムを始めるとき)）
- 有酸素の詳細は [06-cardio.md](../basics/cardio.md)
- 種目は同じ動作パターンのもので置き換えてよい
