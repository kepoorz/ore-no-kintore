# 自重のみ版 PPL × 2

[6日版](../6-day.md) の週間配置を崩さず、負荷手段だけを自重に置き換えた互換版。ホテル・出張先向け。
追加ウェイトなし。床・壁・ベンチ・頑丈なテーブル・低いバーを身体の支持に使うのは可。

- 胸・三頭・脚・コアはかなり高水準で再現できる
- 広背筋・二頭・中部三角筋は弱い。**Pull 日はインバーテッドローができる環境（低いバー / 頑丈なテーブル）を確保する**

> コアの配置・一部セット数がベース文書と少し異なる。食い違う場合はベース文書を優先する。

## 自重での漸進性過負荷

重量を足せないので、次の順に難易度を上げる。

```
回数を増やす → ROM を大きくする → 不利なレバーにする → 片脚・片腕化 → 足を高くする → ボトムで1〜2秒停止
```

例（プッシュアップ）：`10/9/8 → 15/14/12 → 20/20/20 → 足上げプッシュアップへ移行`

30〜40回を延々と続けるより、8〜25回で RIR1〜2 になるバリエーションに変える方が管理しやすい。
