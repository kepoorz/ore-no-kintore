# サプリメント

まず食事と睡眠。サプリは最後の数%。

| サプリ | 判定 | 使い方 | 備考 |
| --- | --- | --- | --- |
| プロテイン | ◎ | 食事で足りない分を補う | 食品扱い |
| クレアチン | ○ | 1日 3〜5g、タイミングは問わない | 研究の蓄積が多い [[Kreider 2017]](../basics/references.md#kreider-2017) |
| マグネシウム | ○（条件付き） | 就寝前に 200〜300mg から | 大量に汗をかく環境で。グリシン酸 / クエン酸を選ぶ。酸化マグネシウムは吸収が悪い |
| BCAA | △ | 総タンパク質が足りていれば不要 | ゼロカロリーの電解質ドリンクとして使う程度 |
| ビタミンD | ○（条件付き） | 日照が少ない生活なら検討 | |

判定：◎ 多くの人に有用 / ○ 条件次第 / △ ほぼ不要
