# 炭水化物源

炭水化物は **抜かずに、量とタイミングで管理する**。運動量が多い日ほど増やし、増やす分は夕食に寄せると眠りやすい。

| 食材 | 量 | 炭水化物 | kcal | 備考 |
| --- | --- | --- | --- | --- |
| ご飯（炊いた状態） | 150g | 約55g | 約235 | 炊いた状態で量る。食べすぎが減量失敗の主因になりやすい |
| バナナ | 1本 | 約25g | 約95 | トレ前の補給に |
| オートミール | 40g | 約25g | 約150 | |
| さつまいも | 100g | 約30g | 約130 | |
| キウイ | 1個 | 約10g | 約50 | |

## トレーニング前

- 朝の高負荷セッションは空腹で行わない。バナナ1本程度を先に
- 低強度・40分未満の有酸素なら空腹でも大きな問題はない
